# Q5｜算法题：变种题怎么答（笔试第 4 题）

> 面试提示：热门算法题的**变种 + 加强**。答法比题目本身更重要——面试官看的是**思路表达 + 边界 + 复杂度 + 优化**。

## 一、标准答题流程（每道题都用这五步，说出口）

1. **复述 + 澄清**：用自己的话重述题目，确认输入规模、数据类型、是否允许重复、是否原地、返回什么。**主动问边界**：空输入？单元素？溢出？有环？
2. **说暴力解 + 复杂度**：先给一个能跑的（O(n²) 也行），证明思路通，并说清它的瓶颈在哪。
3. **给优化思路**：说明用哪种结构把复杂度降下来（哈希表降查找、双指针降嵌套、堆取 TopK、单调栈处理"下一个更大"）。
4. **写代码前先说结构**：变量含义、循环不变量、终止条件。
5. **写完自测**：最小用例、边界用例、一个反例；再说时间复杂度/空间复杂度。

**加分句**：「我先给一个 O(n²) 的思路确保正确，再优化到 O(n)」——大多数面试官吃这套，因为它显示你会权衡。

## 二、高频题的"变种"准备（准备母题，不背题解）

| 母题 | 常见变种 | 关键点 |
|---|---|---|
| 两数之和 | 三数之和、和最接近、子数组和为 K、允许重复 | 哈希 vs 排序+双指针；去重逻辑 |
| 滑动窗口 | 最长无重复子串、最小覆盖子串、窗口内最大值 | 何时扩、何时缩、窗口内用什么结构维护 |
| 链表 | 反转（区间/成组）、环检测、相交、复制带随机指针 | 虚拟头节点、快慢指针、原地修改要保存 next |
| 二叉树 | 层序变种、路径和、序列化、最近公共祖先 | 递归返回什么信息（关键）、迭代用栈 |
| 动态规划 | 背包变种、股票买卖（含冷冻期/手续费）、编辑距离 | 状态定义 > 转移方程；一维滚动优化 |
| 堆 / TopK | 数据流第 K 大、前 K 个高频、合并 K 个有序链表 | 小顶堆大小 K；统计频率再堆 |
| 二分 | 旋转数组、找峰值、答案二分（最小化最大值） | 边界更新 `lo<hi` vs `lo<=hi`；单调性证明 |
| 图 | 拓扑排序、岛屿数量、最短路径（BFS/Dijkstra） | 访问标记时机；BFS 层数即最短 |

## 三、边界清单（每题写完必须过一遍）

- 空数组 / 空字符串 / null
- 单元素
- 全部相同
- 已排序 / 逆序
- 含负数 / 含 0 / 极大值（溢出，用 long）
- 重复值（去重是否要求稳定）
- 越界（数组下标、字符串切片）

## 四、"加强版"怎么应对

面试官把题加强时（比如"数据流版""内存受限版""并发版"），按这个顺序答：

1. **数据流/在线**：不能回头扫 → 用堆/单调队列/哈希 + 增量维护。
2. **内存受限**：不能全量加载 → 分块 + 外部排序；或概率结构（布隆过滤器、HyperLogLog、Count-Min Sketch）+ 明确说"允许误差"。
3. **并发版**：先划分无共享的分片 → 每分片独立处理 → 最后归并；需要全局有序就用分段锁或单写多读。
4. **多机/分布式**：哈希分片 → 局部 TopK → 全局归并；说明数据倾斜怎么处理。

**示例回答（TopK 的加强版）**：
> 单机内存够，用小顶堆 O(n log k)；每天上亿条数据、内存受限，我会分片统计频率（哈希分片到多台）→ 每片各自 TopK → 汇总后再取 TopK，并注意热门 key 的倾斜（加盐打散）。

## 五、复杂度速记

- 哈希查找 O(1) 平均；排序 O(n log n)；堆操作 O(log n)；二分 O(log n)
- 字符串匹配 KMP O(n+m)；滑动窗口 O(n)；并查集近似 O(α(n))
- 递归要能说出**栈深度**（链表/树退化成链时的风险）

## 六、心态与话术

- 卡住时：**先说当前思路和卡点**，不要沉默硬想。面试官经常给提示，给提示后要接住并推进。
- 写错时：主动说"这里我写错了，应该是 X"，比被指出好。
- 收尾时：主动说"如果要进一步优化，我会考虑 X（空间/并行/近似）"。
