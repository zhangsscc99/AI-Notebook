# 西门子面试复习（2026-11-16）

面试结构：笔试/设计题 + 逐题追问 → 项目深挖（2 位面试官）→ 英语口语 + 文化匹配（2 位面试官）。

## 问答清单（按面试顺序）

### 第 1 小时：笔试 / 设计题
- 01-Agent系统设计 —— 五层架构 + 两条横切 + 追问预案（Agent 设计题）
- 03-SOLID与设计模式 —— 五原则 + 6 个模式 + 类图/时序图
- 04-并发流量控制与连接管理 —— 并发模型、线程池、限流算法、背压、TCP、连接池、超时分层、重连
- 05-算法题应对 —— 五步答法、母题与变种、边界清单、加强版思路、话术

### 第 2 小时：项目深挖
- 02-AI-Notebook项目复盘 —— 背景 / 架构 / 难点 / 量化数据 / 优化空间
- 06-项目深挖与行为面 —— 三段式介绍、五个必答追问、类设计现场题、反问清单

### 第 3 小时：英语 + 文化
- 07-英语口语与西门子文化 —— 英文自我介绍、项目英文稿、高频追问、关键词表、公司背景

## 当天使用顺序

1. 前 30 分钟：只读 01 和 03 的「一句话答案」
2. 候场：读 06 的自我介绍三段式 + 07 的英文自我介绍
3. 笔试中：设计题先写骨架（分层 + 关键流程），主动说「这里我偏粗粒度，可以展开讲」

## 输出策略

- 设计题：先结构后细节，画分层、写关键流程、标注取舍
- 每题留一个优化钩子：「如果要进一步提高，我会考虑 X」
- 不知道就说不知道，然后说「我会这样去验证」—— 比编造好
