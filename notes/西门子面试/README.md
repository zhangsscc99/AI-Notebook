## 待补（按优先级）

1. SOLID 五原则 + 本项目里的真实例子（单一职责：内容管线 vs 渲染；开闭：工具插件化；里氏：Provider 抽象；接口隔离：只读/可写工具；依赖倒置：编排层依赖抽象工具接口）
2. 设计模式落地：策略（模型降级链）、模板方法（Agent Loop）、观察者（事件/通知）、工厂（工具注册）、装饰器（重试/超时/日志中间件）
3. UML：类图（Agent/Tool/Memory 三者的依赖关系）、时序图（一次工具调用的完整链路）
4. 并发与流量：线程池 vs 协程、背压、限流算法（令牌桶/漏桶/滑动窗口）、连接池与超时分层
5. 算法：热门题变种 + 边界条件 + 复杂度分析
6. 英文自我介绍 + 项目英文表述 + Why Siemens Healthineers

## 复习节奏建议

- 面试前 30 分钟：只过两篇问答的「30 秒版」+「追问预案」
