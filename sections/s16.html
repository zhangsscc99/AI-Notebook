FTS 虚表是什么

FTS 是 SQLite 的 Full Text Search，全文搜索。所谓“虚表”就是 SQLite 里的 virtual table：它看起来像普通表，可以查询，但底层由扩展模块维护特殊索引结构。

OpenClaw 创建的 FTS 虚表大概长这样：

CREATE VIRTUAL TABLE chunks_fts USING fts5(
  text,
  id UNINDEXED,
  path UNINDEXED,
  source UNINDEXED,
  model UNINDEXED,
  start_line UNINDEXED,
  end_line UNINDEXED
);

这里真正参与全文搜索的是 text。其他字段标成 UNINDEXED，意思是它们只是跟结果一起返回的元数据，不参与倒排索引。

它解决的是关键词搜索问题，比如错误码、配置键、文件名片段、精确术语。vector search 擅长语义相似，但对精确字符串不一定可靠；FTS 则补上这个短板。

所以 hybrid search 里的 “BM25/keyword path” 就依赖 FTS 虚表。它让 memory_search 不只是语义相似搜索，也能找精确词。
