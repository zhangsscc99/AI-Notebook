vector search 是怎么做的

如果 sqlite-vec 可用，系统会直接走原生向量 KNN；如果不可用，就退化为读取已保存 embedding，再在进程内做 cosine similarity。

extensions/memory-core/src/memory/manager-search.ts
if (await ensureVectorReady(...)) {
  // sqlite-vec native KNN
} else {
  // fallback: parse embeddings + cosineSimilarity
}

所以它不是“没有向量扩展就完全废掉”，而是会优雅降级。
