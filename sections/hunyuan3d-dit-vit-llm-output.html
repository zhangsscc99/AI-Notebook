项目用的是 DiT 还是 ViT，和 LLM 的输出原理有什么不同

结论先说：混元3D 的 3D 形状生成主干是 DiT，不是普通 ViT；但它的图片条件编码器里会用 CLIP / DINOv2 这类 ViT-style 图像 encoder。所以准确说法是：ViT 类模型负责编码输入图片条件，DiT 负责在 3D shape latent 空间做生成。

一句话：LLM 输出的是下一个离散 token 的 logits；Hunyuan3D-DiT 输出的是连续 shape latent 的 denoising / flow 更新量。这个更新量还不是 mesh，必须经过 scheduler 迭代更新 latent，再由 ShapeVAE、volume decoder、surface extractor 才变成 3D mesh。

1. 为什么叫 DiT

DiT = Diffusion Transformer。它本质上是 Transformer，但用在 diffusion / flow matching 的去噪过程里。源码里的类名就是 Hunyuan3DDiT，pipeline 入口是 Hunyuan3DDiTFlowMatchingPipeline。

2. 为什么又看到 ViT

ViT 是图像编码器范式。混元3D 的 conditioner.py 里有 CLIPImageEncoder、DinoImageEncoder、DinoImageEncoderMV。这些负责把 2D 图片变成条件 token，不是最终生成 mesh 的主干。

3. DiT 和 ViT 的关系

DiT 借用了 Transformer/ViT 的 token + attention + MLP 结构，但任务不同。ViT 常用于图像理解/分类/特征提取；DiT 用 Transformer 当扩散模型 denoiser，每一步输入 noisy latent 和 timestep，输出去噪方向。

4. 这里不是 autoregressive decoder

LLM decoder 一次预测下一个 token；Hunyuan3D-DiT 每一步预测整个 shape latent 的更新量。它不是“先生成第一个顶点，再生成第二个顶点”，而是在连续 latent 空间里整体迭代。

从源码看，shape 生成的关键模块是：

图片条件 encoder。prepare_image() 预处理图片，encode_cond() 调用 conditioner。conditioner 内部可用 CLIP / DINOv2 图像 encoder 输出 contexts['main']。
随机 shape latent。prepare_latents() 根据 self.vae.latent_shape 创建随机连续 latent，形状是 (batch_size, num_latents, embed_dim)。
DiT denoiser。Hunyuan3DDiT.forward(x, t, contexts) 把 noisy latent 经 latent_in 投影，把 timestep 经 time_in 编码，把图片条件经 cond_in 投影。
双流/单流 Transformer blocks。源码先跑 double_blocks，让 latent token 和 condition token 交互；再把 condition 和 latent 拼起来跑 single_blocks。
final_layer 输出 latent 更新量。LastLayer 用 LayerNorm + adaLN modulation + Linear，把 hidden state 投回 out_channels。源码里 out_channels = in_channels，也就是输出维度对齐 shape latent 维度。
scheduler 更新 latent。pipeline 里 noise_pred = self.model(...) 后，不是直接得到 mesh，而是调用 self.scheduler.step(noise_pred, t, latents)，把 latent 推进一步。
ShapeVAE 输出 mesh。采样完成后 _export() 调 self.vae(latents) 和 self.vae.latents2mesh()，再由 volume decoder + surface extractor 变成 mesh。

和 LLM 对比，输出原理差异非常大：

LLM 输出：token logits

典型 LLM 输入 token ids，Transformer decoder 输出每个词表 token 的 logits。采样器从 softmax 概率里选下一个 token，然后把 token append 回上下文继续生成。

context tokens -> Transformer -> vocab logits -> sample token
循环单位：一个离散文本 token

Hunyuan3D 输出：latent 更新量

Hunyuan3D-DiT 输入 noisy shape latent、timestep、图片条件，输出与 latent 同形状的连续向量。这个向量是 scheduler 用来更新 latent 的 denoising / flow 预测，不是词表概率。

noisy shape latent + timestep + image condition
  -> DiT
  -> noise_pred / velocity-like update
  -> scheduler.step 更新 latent

最终“输出组件”不是一个，而是一条链：

组件 A：Hunyuan3DDiT.final_layer

这是生成主干的直接输出头。它把 Transformer hidden states 投影回 shape latent 的通道维度，输出 denoising 预测。注意：这里仍然是 latent 空间，不是 mesh。

组件 B：scheduler

scheduler 决定每一步怎么用 noise_pred 更新 latents。没有 scheduler，DiT 的输出只是一步预测，不会形成完整生成轨迹。

组件 C：ShapeVAE.forward

采样结束后，latent 先经过 post_kl 和 VAE 内部 Transformer，变成几何 decoder 能使用的 latent 表示。

组件 D：volume decoder + surface extractor

latents2mesh() 先用 volume decoder 得到 grid_logits，再用 marching cubes / surface extractor 抽取三角网格表面，最终得到 trimesh。

一句话流程：
CLIP/DINO ViT encoder：2D 图片 -> 条件 token
Hunyuan3D-DiT：noisy shape latent + 条件 token + timestep -> latent 更新量
Scheduler：多步更新 latent
ShapeVAE：latent -> volume field
Surface extractor：volume field -> mesh
Paint pipeline：mesh + 图片 -> UV texture -> textured mesh / GLB
最短总结：用的是 DiT 做生成，ViT/CLIP/DINO 主要做图片条件编码。它和 LLM 最大区别是：LLM 输出离散 token 概率；混元3D 输出连续 3D latent 的去噪方向，最后靠 VAE 和 surface extraction 才变成真正的 3D 模型。
