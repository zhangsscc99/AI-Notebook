query()：模型-工具循环怎么跑

src/query.ts 是真正的 agent loop。它不是简单“问一次模型就结束”，而是一个 while (true) 循环：每轮先整理上下文，再调用模型流式输出；如果输出包含 tool_use，就执行工具，把 tool_result 作为 user message 放回上下文，然后继续下一轮。

从上次 compact boundary 后取消息，应用 tool result budget、snip、microcompact、context collapse、auto compact。
拼接 system prompt、user context、system context，选择当前模型和 fallback model。
调用 deps.callModel() 流式收 assistant 消息；发现 tool_use block 时记录到 toolUseBlocks。
如果没有 tool_use，执行 stop hooks、token budget continuation 判断，然后返回 completed。
如果有 tool_use，交给工具编排层执行；工具结果归一化为 user tool_result，追加回下一轮模型上下文。
这就是 Claude Code 的基本“工作流”：模型不是直接改文件，而是反复产生 tool_use，客户端验证权限并执行工具，再把结果喂回模型，直到模型不再请求工具。
