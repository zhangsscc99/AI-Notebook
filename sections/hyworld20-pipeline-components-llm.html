HY-World 2.0 世界模型 pipeline 是怎么样的，用了哪些组件，用了 LLM 吗

HY-World 2.0 的 pipeline 不是“一个 LLM 直接吐出 3D 世界”。源码里更准确的理解是：LLM/VLM 负责理解、标注、规划和生成文本条件；真正生成/重建 3D 世界的是全景生成模型、视频扩散模型、几何 Transformer、深度/法线/点云预测、3DGS 优化和 mesh 导出组件。

一句话：HY-World 2.0 = 文本/图片/视频输入 → 全景或多视角条件 → VLM 辅助规划/描述 → WorldStereo 沿轨迹扩展新视角 → WorldMirror/几何模块预测相机、深度、法线、点云、GS 特征 → 3DGS/mesh 组合成可导航世界。用了 LLM/VLM，但 LLM 不是最终几何生成器。

1. 它有两条主 pipeline：生成世界和重建世界

World Generation：从想象生成世界

文本 / 单张图
  → HY-Pano 2.0 生成 360° 全景图
  → WorldNav / VLM / NavMesh 规划相机轨迹
  → point-cloud trajectory rendering 渲染轨迹条件
  → VLM 给轨迹视频写 caption
  → WorldStereo 2.0 扩展新视角关键帧
  → gen_gs_data 整理图片、深度、法线、相机
  → world_gs_trainer 优化 3DGS
  → 导出 PLY / SPZ / mesh / viewer

这条线解决的是：给一个提示词或单图，系统自己补全一个可以移动视角、可以渲染、可以导出的 3D 场景。

World Reconstruction：从真实多视角重建世界

多视角图片 / 视频帧
  → WorldMirrorPipeline 预处理输入
  → WorldMirror / VisualGeometryTransformer 跨视角建模
  → CameraHead 预测相机
  → DPTHead 预测深度、法线、点云
  → GS head / renderer 预测或渲染 Gaussian 特征
  → save_results 保存相机、depth、normal、points、3DGS
  → 可进一步导出 3D 资产

这条线解决的是：已有多张真实照片或视频时，把它们变成 digital twin / 3D reconstruction。

2. World Generation 的线性执行顺序

HY-Pano 2.0：先把输入变成全景起点。hyworld2/panogen/pipeline.py 使用 HunyuanImage3ForCausalMM；另一个轻量后端 pipeline_with_qwen_image.py 基于 Qwen-Image-Edit。这里的目标是得到 360° panorama，不是直接得到 3D mesh。
WorldNav：用视觉理解和几何约束规划路线。traj_generate.py 会加载 MoGe、ZIM、GroundingDINO、SAM3，并通过 OpenAI-compatible client 调 vLLM 上的 Qwen3-VL，做环境分类、目标识别、导航目标选择；再结合 Recast/NavMesh 做避障路径。
Trajectory Rendering：把计划路线渲染成后续模型能吃的条件。traj_render.py 沿相机轨迹渲染点云/深度/视频条件，并调用 get_traj_caption() 让 VLM 给轨迹内容生成 caption。
WorldStereo 2.0：真正扩展新视角。video_gen.py 加载 WorldStereo.from_pretrained("hanshanxue/WorldStereo")。README 里说明它是 diffusion-based video generation model，Transformer backbone 扩展自 WanTransformer3DModel，并加入 camera embeddings 和 ControlNet point-cloud render 条件。
PanoramaMemoryBank：保持跨轨迹一致性。src/retrieval_wm.py 里的 PanoramaMemoryBank 会检索已有全景/参考帧，给新轨迹生成提供 reference panorama injection，减少不同路线之间风格、物体和几何漂移。
3DGS 数据准备和训练。gen_gs_data.py 整理帧、深度、法线、相机参数；world_gs_trainer.py 用 gsplat/MaskGaussian、depth/normal/LPIPS/SSIM 等 loss 优化 Gaussian Splatting，最后导出 .ply、.spz 或 mesh。

3. 主要组件各自负责什么

HY-Pano 2.0

全景图生成组件。输入文本/图片，输出 360° equirectangular panorama。它给后续世界生成提供“初始球面环境”。

Qwen3-VL / vLLM / OpenAI API

视觉语言理解组件。traj_generate.py 和 vlm_utils.py 用 OpenAI(api_key="EMPTY", base_url="http://.../v1") 调本地 vLLM 服务，模型名默认 Qwen/Qwen3-VL-8B-Instruct。

MoGe / ZIM / GroundingDINO / SAM3

几何和语义感知组件。MoGe 给深度/法线几何先验；ZIM、GroundingDINO、SAM3 做分割、检测、语义 mask，辅助导航、天空/物体处理和后续一致性。

Recast / NavMesh

传统导航组件。它不是神经网络，而是把可走区域、障碍物、路径搜索组织起来，让相机轨迹不是乱飞，而是更像在可通行空间里移动。

WorldStereo 2.0

世界扩展的核心生成模型。它基于视频扩散/Transformer，把轨迹条件、点云渲染条件、文本 caption、参考记忆变成沿相机路径的新视角关键帧。

WorldMirror 2.0

重建和几何预测组件。WorldMirror 里主干是 VisualGeometryTransformer，再接 CameraHead、DPTHead、GS 相关 head，输出相机、深度、法线、点云、GS 特征。

UMT5 / text encoder

WorldStereo pipeline 里有 UMT5EncoderModel 和 tokenizer，_get_t5_prompt_embeds() / encode_prompt() 把 caption/prompt 编成条件 embedding。这是文本条件编码器，不是一个负责规划的聊天 LLM。

3DGS / gsplat / mesh export

最终资产化组件。3DGS 负责把多视角结果优化成可实时渲染的 Gaussian 表示；再导出 PLY、SPZ、mesh，才变成用户能保存、查看、导入引擎的 3D 世界。

4. 到底用了 LLM 吗？用了，但位置要分清

用了 LLM/VLM。最明确的位置是 World Generation 的轨迹规划和轨迹 caption：

// traj_generate.py：OpenAI-compatible 调本地 vLLM
client = OpenAI(api_key="EMPTY", base_url=f"http://{LLM_ADDR}:{LLM_PORT}/v1")
MODEL_NAME = "Qwen/Qwen3-VL-8B-Instruct"
response = client.chat.completions.create(
    model=MODEL_NAME,
    messages=messages,
    max_tokens=1024,
    temperature=0.0,
)

traj_render.py 还会调用 get_traj_caption()：从轨迹视频里均匀采样若干帧，转成 base64 image_url，发给 Qwen3-VL，让它生成视觉描述；这个 caption 后面会作为 WorldStereo 的文本条件之一。

LLM/VLM 做什么

  • 判断场景类型，比如室内、街景、自然环境。
  • 识别值得探索的目标和区域。
  • 给轨迹视频写自然语言 caption。
  • 把视觉语义转成后续生成模型更容易使用的文本条件。

LLM/VLM 不做什么

  • 不直接输出 3DGS 参数。
  • 不直接输出 mesh 顶点和面。
  • 不负责深度/法线/相机的主要数值预测。
  • 不替代 WorldStereo、WorldMirror 和 3DGS 优化。

5. 一个具体例子：输入一张房间照片后发生什么

输入：一张房间照片

1. HY-Pano 2.0 把照片扩成 360° 室内全景。
2. Qwen3-VL 看全景，判断这是室内场景，识别门、桌子、窗户、走廊等目标。
3. MoGe 估计深度/法线，SAM3/GroundingDINO/ZIM 提供 mask 和语义区域。
4. NavMesh 根据可走区域规划相机路线：例如从门口走向窗户，再绕桌子一圈。
5. traj_render.py 沿路线渲染点云条件视频，并让 Qwen3-VL 给这条路线写 caption。
6. WorldStereo 2.0 根据 caption、相机轨迹、点云渲染、参考全景记忆，生成沿路线的新视角关键帧。
7. gen_gs_data.py 把这些图像、深度、法线、相机参数整理成 3DGS 训练数据。
8. world_gs_trainer.py 优化 Gaussian Splatting，导出可实时浏览的 3D 房间。
所以要记住这个分工：LLM/VLM 是“语义理解 + 规划辅助 + caption 生成器”；WorldStereo 是“沿轨迹扩展像素/视角的生成器”；WorldMirror 是“多视角几何重建器”；3DGS 是“最终 3D 世界资产的可渲染表示”。HY-World 2.0 的强点正是把这些组件工程化串起来，而不是把所有事情都压给一个 LLM。
