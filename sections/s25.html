chunking 规则

chunking 的目标是把 markdown / transcript 切成适合 embedding 和检索的片段，同时保留原始行号，方便后续 memory_get 回读。

按 token 预算估算字符

chunkMarkdown 根据 chunking.tokens 和内部字符估算上限决定每块大小，不是直接调用 tokenizer 精确切。

支持 overlap

每次 flush 一个 chunk 后，会按 chunking.overlap 保留尾部内容到下一块，减少跨 chunk 信息断裂。

保留 startLine / endLine

每个 chunk 都记录起止行。session transcript 会先转成文本，再用 lineMap 把内容行号 remap 回原 transcript 行。

CJK 长行处理

对中文、日文等 CJK-heavy 长文本，代码会做更细的切分，并避免切断 UTF-16 surrogate pair。

源码核心流程可以简化成：

content.split("\\n")
for each line:
  split long line into segments
  if current chunk exceeds budget:
    flush()
    carryOverlap()
  append segment with lineNo
flush()
