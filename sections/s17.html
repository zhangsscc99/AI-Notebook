memory_get 工具详解

memory_get 的定位不是搜索，而是按路径精确读取一段记忆文件。通常流程是先用 memory_search 找到相关片段，再用 memory_get 拉取更完整、可核对的原文行。

它的参数很少：

  • path：必填，要读取的 memory 文件路径。
  • from：可选，从第几行开始读。
  • lines：可选，读取多少行。
  • corpus：可选，memory、wiki、all。
MemoryGetSchema = {
  path: string,
  from?: number,
  lines?: number,
  corpus?: "memory" | "wiki" | "all"
}

执行时会先解析当前 agent 和配置。如果 memory search 被禁用，工具不会被创建。真正执行时，它按 corpus 和 backend 分支：

  • corpus=wiki：直接去 registered corpus supplement 里读，比如 memory-wiki。
  • builtin backend：调用 readAgentMemoryFile，再进入 readMemoryFile。
  • qmd backend：先拿 MemorySearchManager，再调用它的 readFile。
  • corpus=all：如果 memory 文件读取失败，会尝试从 supplement 里 fallback。

它返回的核心结果是：

{
  path: string,
  text: string,
  from?: number,
  lines?: number,
  truncated?: true,
  nextFrom?: number
}
memory_get 的关键点是“安全精确读取”：它不会全量暴力读取所有 memory，也不会随便读 workspace 里任意文件。
