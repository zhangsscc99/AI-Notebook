VRAG 用的向量数据库是什么

源码里没有接 Milvus、Qdrant、Weaviate、Elasticsearch dense vector 这类独立向量数据库。它用的是本地 FAISS 索引。

准确说：VRAG 用 FAISS 做向量索引，不是一个带服务端、权限、多租户、过滤表达式的完整向量数据库。它把 FAISS index 文件和 metadata JSONL 文件放在本地磁盘。

索引类型

SearchEngine.build_index() 新建索引时用 faiss.IndexFlatIP(self.dimension)。Flat 表示不做 IVF/HNSW/PQ 压缩近似，IP 表示 inner product 相似度。

索引文件

索引保存为 {model_name}_faiss_index.bin，通过 faiss.write_index() 写入，通过 faiss.read_index() 加载。

元数据文件

每条向量对应的文件信息写入 {model_name}_file_data_list.jsonl，包含 type、file_path、文本 content 等。

多索引合并

load_multi_index_corpus_together() 可以加载多个 index 目录，用 self.index.merge_from(...) 合并 FAISS index，同时 extend metadata。

所以它更像一个轻量本地检索引擎：FAISS 负责向量近邻搜索，FastAPI 负责把它包装成 /search 服务。
