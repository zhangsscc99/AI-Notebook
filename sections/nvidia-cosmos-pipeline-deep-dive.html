NVIDIA Cosmos 的 pipeline 详解

Cosmos 的 pipeline 要分三层看：Diffusion Text2World / Video2World、Autoregressive Video2World、以及所有路线共用的 Tokenizer / Text Encoder / Guardrail / Prompt Upsampler。它不是一个单文件单模型，而是一套把输入条件、latent/token 表示、生成主干和安全过滤串起来的世界视频生成系统。

一句话：Cosmos pipeline 的核心是“先把文本和视频压到模型能处理的条件/latent/token 空间，再用 diffusion 或 autoregressive 主干生成未来世界视频，最后解码回像素并做安全过滤”。

1. Diffusion Text2World：文本生成世界视频

输入 prompt。入口是 cosmos1/models/diffusion/inference/text2world.py，核心类是 DiffusionText2WorldGenerationPipeline。
pre-Guard。BaseWorldGenerationPipeline 会调用 text guardrail，先检查输入 prompt 是否安全。
Prompt Upsampler。如果启用，_run_prompt_upsampler_on_prompt() 会把短 prompt 扩写成更具体的影视/场景描述，再跑一次 guardrail。
T5 文本编码。CosmosT5TextEncoder 默认加载 google-t5/t5-11b，输出 [batch, 512, hidden] 级别的文本 hidden states，作为 diffusion cross-attention 条件。
构造视频 latent shape。get_video_batch() 根据目标 height/width/fps/num_video_frames 和 tokenizer 压缩率，算出 latent 的 [C,T,H,W]。
从噪声开始采样。generate_world_from_text() 用随机噪声 x_sigma_max 初始化 latent，然后调用 model.generate_samples_from_batch() 迭代去噪。
DiT 去噪主干。DiffusionT2WModel.denoise() 把 noisy latent、噪声级别 sigma、文本条件送进 GeneralDIT，预测干净 latent x0 和噪声 eps。
Tokenizer decoder 解码视频。_run_tokenizer_decoding() 调 self.model.decode(sample)，把 latent 还原成 [T,H,W,C] 视频帧。
post-Guard。生成视频再经过 video content safety filter 和 face blur，安全才返回。

2. Diffusion Video2World：给图片/短视频，生成后续世界

Video2World 和 Text2World 的差别是多了一个视觉条件 latent。

输入图片/视频 + prompt
  → 读入并 resize/crop 到模型需要的尺寸
  → tokenizer.encode 得到 condition_latent
  → 前 N 个 latent 时间步标为 condition region
  → 其余时间步从噪声开始生成
  → DiT 每一步同时看文本条件和视频条件 mask
  → 保留输入条件区域，生成未来区域
  → tokenizer.decode 输出视频

源码里关键点在 DiffusionV2WModel：get_condition_latent() 先把输入图/视频编码成 latent；add_condition_video_indicator_and_video_input_mask() 用 condition_video_indicator 标出哪些时间步是输入条件；denoise() 会把条件区域的 latent 和生成区域的 noisy latent 拼在一起，并在 x0_pred_replaced 里把条件区替换回 ground-truth latent，避免第一段输入被模型乱改。

3. Autoregressive pipeline：先预测视觉 token，再用 diffusion decoder 增强

输入上下文。Base AR 接图片/视频；AR Video2World 还接文本 prompt。典型是 1 张图或 9 帧短视频，生成到 33 帧。
视频 tokenizer 离散化。DiscreteMultimodalTokenizer 把视频编码成离散 video tokens。这里 Cosmos 更接近 LLM 的 token 生成方式，但 token 不是文字，而是视频 latent 网格上的视觉 token。
AR Transformer 预测未来 token。generate_partial_tokens_from_data_batch() 计算还需要生成多少 token，然后 generate_video_from_tokens() 调 self.model.generate()，用 top-p、temperature 等采样参数生成后续视觉 token。
reshape 成视频 token 网格。生成出来的一维 token 序列会被 reshape 成 [B,T,H,W] 的视频 token 网格。
tokenizer decode 初步视频。video_tokenizer.decode(indices_tensor) 把离散 token 解码回视频。
diffusion decoder 可选增强。diffusion_decoder_process_tokens() 用 diffusion decoder 对 AR token 结果做画质增强和细节补足。
输出安全过滤。同样走 post-Guard，最后返回 numpy 视频帧。

4. 三个底座组件要单独记

Cosmos Tokenizer

它是视频世界模型的压缩器。Diffusion 走 continuous latent；AR 走 discrete visual token。README 里写到空间压缩 8x/16x、时间压缩 4x/8x，最大总压缩可到 2048x。没有它，大模型直接处理原始视频像素成本太高。

GeneralDIT

Diffusion 路线的核心网络。配置里 FADITV2Config 使用 GeneralDIT，输入通道和输出通道都是 latent 通道，带 3D RoPE、cross-attention、时空 patch，用于在视频 latent 空间去噪。

AutoRegressiveModel

AR 路线的核心网络。源码注释虽然沿用了“text generation”的表述，但实际这里的 vocab 被扩展为 video tokenizer 的 vocab，模型生成的是视觉 token，而不是自然语言 token。

Guardrail

pre-Guard 检查输入文本；post-Guard 检查输出视频并做人脸模糊。它不保证物理真实，但保证安全合规是推理链路的一部分。

记忆方式：Diffusion Cosmos = prompt/视频条件 → T5/condition latent → DiT latent 去噪 → tokenizer decode；AR Cosmos = 输入视频 token → Transformer 预测未来 token → tokenizer/diffusion decoder 还原视频。
