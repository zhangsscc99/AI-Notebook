启动时如何注入 memory，以及 compaction 前为什么会 flush

启动时并不会把全部 memory 都塞进模型上下文，而是会受预算限制：

  • 每个文件最大字节数
  • 每个文件最大字符数
  • 总注入字符上限
  • 默认只带最近几天 daily memory
src/auto-reply/reply/startup-context.ts
- maxFileBytes
- maxFileChars
- maxTotalChars
- dailyMemoryDays

另外，在 compaction 前，OpenClaw 会做一次 memory flush，提醒系统把值得保留的东西写进当日 memory 文件里。

extensions/memory-core/src/flush-plan.ts
- write to memory/YYYY-MM-DD.md
- append only
- do not overwrite MEMORY.md / DREAMS.md / AGENTS.md
设计意图非常清楚：在上下文被压缩前，先把重要信息落盘，防止 compaction 后“只剩摘要、原信息丢失”。
