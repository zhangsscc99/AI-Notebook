latent 是如何解码成 mesh 的，是按规则还是模型

latent 到 mesh 不是一个简单规则，也不是 DiT 直接吐顶点。它分两段：先由神经网络把 latent 解码成 3D 空间里的场函数 / grid logits；再由确定性几何算法从这个场里抽取表面。

一句话：latent → volume field 是模型学出来的；volume field → mesh 是几何算法抽出来的。前半段是神经网络，后半段通常是 marching cubes / DMC 这类规则化 surface extraction。
采样结束得到 shape latent。pipeline 的 _export() 收到最终 latents，如果输出不是 latent，就开始解码。
先做 scale 和 ShapeVAE forward。源码先 latents = 1. / self.vae.scale_factor * latents，再 latents = self.vae(latents)。ShapeVAE 内部用 post_kl 和 Transformer 处理 latent。
volume decoder 查询 3D 网格点。VanillaVolumeDecoder 会在 bounding box 里生成密集 3D query points，比如按 octree resolution 生成 x/y/z 网格。
geo_decoder 预测每个点的 logit。volume decoder 把 query points 分 chunk 喂给 geo_decoder(queries, latents)，得到每个 3D 位置的 occupancy/SDF-like logit。
得到 grid_logits。所有 chunk 拼回一个 3D grid：grid_logits = [B, D, D, D]。这可以理解成“空间中每个格点在物体内外/表面附近的分数”。
surface extractor 抽 mesh。MCSurfaceExtractor 调 measure.marching_cubes(grid_logit, mc_level)，从等值面里抽出 vertices 和 faces。
转成 trimesh / GLB。抽出的顶点和面会包装成 Latent2MeshOutput，再由 export_to_trimesh() 转成 trimesh.Trimesh，最终导出 glb。

哪些是模型学的

ShapeVAE 的 latent 表示、Transformer 处理、geo_decoder 如何根据 latent 和 3D 坐标预测 logit，这些是神经网络学出来的。

哪些是规则算法

在 3D bounding box 里采样网格点、把 logits reshape 成 3D grid、marching cubes 从等值面抽 vertices/faces，这些是确定性几何算法。

marching cubes 是什么

它把 3D 标量场里的某个等值面抽成三角网格。比如 mc_level=0 时，就找 logit 从负到正穿过 0 的地方，拼成物体表面。

为什么不是直接输出顶点

直接输出顶点/面很难处理可变拓扑。用场函数再抽表面，可以自然表达洞、多个部件、复杂拓扑，最后由几何算法统一生成 mesh。

latent -> mesh：
final latent
  -> ShapeVAE.forward(latent)
  -> volume_decoder: 对 3D 网格点逐点查询 geo_decoder
  -> grid_logits: 3D 标量场
  -> surface_extractor: marching_cubes / DMC
  -> vertices + faces
  -> trimesh / glb
最短总结：latent 解码成 mesh 是“神经场预测 + 几何抽表面”的组合。不是纯规则，也不是模型直接输出 mesh 文件。
