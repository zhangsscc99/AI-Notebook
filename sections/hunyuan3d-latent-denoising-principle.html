3D latent 迭代去噪是什么原理

3D latent 迭代去噪的核心是：先不要直接生成 mesh，而是在 ShapeVAE 定义的连续 3D 隐空间里，从一团随机噪声 latent 出发，经过很多步把它推向“像真实 3D 物体”的 clean shape latent。

一句话：混元3D 的 DiT 每一步不是输出最终 3D 模型，而是看当前 noisy latent、时间步 t、图片条件，预测“这个 latent 应该往哪个方向移动”；scheduler 用这个方向更新 latent，多步之后才得到 clean latent。
训练时有 clean latent。Hunyuan3D-2.1 训练代码里，真实 3D surface 会先通过 ShapeVAE.encode(surface) 编成 clean latent，记作 x1。
再采样噪声 latent。transport.sample(x1) 里用 x0 = randn_like(x1) 生成随机噪声 latent。
构造中间状态 xt。ICPlan.compute_mu_t() 的线性路径可以理解为 xt = t * x1 + (1 - t) * x0：t 越小越像噪声，t 越大越像真实 3D latent。
模型学会预测移动方向。training_losses() 把 xt、t 和图片条件送入模型，模型输出一个与 latent 同形状的向量，并用 MSE 对齐目标方向 ut。
推理时反过来走。推理没有真实 x1，所以从随机 latent 开始；每一步 DiT 预测方向，scheduler 通过欧拉步更新 latent，逐步接近 clean shape latent。

为什么不直接生成 mesh

mesh 是可变拓扑的顶点/面集合，长度不固定，很难像文本 token 一样直接生成。latent 是固定形状的连续张量，适合 Transformer/DiT 做并行建模和多步去噪。

图片条件起什么作用

图片经 DINO/CLIP encoder 变成 condition tokens。DiT 预测每一步 latent 移动方向时，会结合这些条件，让 latent 往“符合输入图片的 3D 物体”方向走。

迭代去噪和 LLM 有什么不同

LLM 是把 token 一个一个 append 到序列后面；3D latent 去噪是同一个 latent tensor 被反复整体修改。它不是生成第 1 个顶点、第 2 个顶点，而是整块 3D 表示逐步 refinement。

为什么要很多步

一步从纯噪声跳到好 3D 很难。flow matching 把这个难问题拆成很多小步，每一步只预测局部方向，最终轨迹更稳定。

训练：
clean 3D surface -> ShapeVAE.encode -> clean latent x1
noise latent x0 = randn_like(x1)
xt = interpolate(x0, x1, t)
DiT(xt, t, image_condition) -> velocity target
loss = MSE(pred, target)

推理：
latent = random noise
for t in timesteps:
    direction = DiT(latent, t, image_condition)
    latent = scheduler.step(direction, t, latent)
mesh = ShapeVAE.latents2mesh(latent)
最短记忆：3D latent 迭代去噪 = 在固定形状的 3D 隐空间里走一条从噪声到真实物体的轨迹。DiT 负责预测方向，scheduler 负责按时间步更新 latent。
