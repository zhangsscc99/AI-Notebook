embedding 模型用的是啥

这里没有一个全局固定答案，取决于你走的是 builtin memory 后端 还是 QMD 后端，以及配置里的 provider / model 怎么设。

builtin 后端

builtin memory 的 embedding 配置在 agents.defaults.memorySearch。如果显式设置 provider 和 model，就用你指定的模型；如果 model 为空，就用该 provider adapter 的默认模型。

auto provider

如果 provider 是 auto 或没有显式设置，OpenClaw 会按可用性选择 provider：local、github-copilot、openai、gemini、voyage、mistral、deepinfra、bedrock 等。ollama 支持但通常需要显式配置。

local 默认模型

本地 embedding adapter 的默认模型是 hf:ggml-org/embeddinggemma-300m-qat-q8_0-GGUF/embeddinggemma-300m-qat-Q8_0.gguf。文档也把它简称为 embeddinggemma-300m-qat-Q8_0.gguf。

OpenAI 示例模型

OpenClaw 配置文档里的 OpenAI 示例使用 text-embedding-3-small。这不是所有安装的强制默认值，而是显式选择 OpenAI provider 时常见的配置示例。

builtin 后端的典型配置：

{
  agents: {
    defaults: {
      memorySearch: {
        provider: "openai",
        model: "text-embedding-3-small"
      }
    }
  }
}

如果使用 QMD 后端，embedding / rerank / generate 模型主要由 QMD 自己控制。OpenClaw 不在普通 memorySearch 配置里替 QMD 指定模型，而是把这些环境变量原样传给 QMD：

export QMD_EMBED_MODEL="hf:Qwen/Qwen3-Embedding-0.6B-GGUF/Qwen3-Embedding-0.6B-Q8_0.gguf"
export QMD_RERANK_MODEL="/absolute/path/to/reranker.gguf"
export QMD_GENERATE_MODEL="/absolute/path/to/generator.gguf"
判断当前到底用哪个 embedding 模型：先看 memory.backend。如果是 builtin，看 agents.defaults.memorySearch.provider/model 和 provider auto-select 结果；如果是 QMD，看 QMD_EMBED_MODEL 或 QMD 自己下载/选择的模型。
