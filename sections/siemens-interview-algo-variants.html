面试说要考「热门算法题的变种，并做加强/升级」。这节不讲刷题，讲怎么答——面试官真正看的是：思路表达、边界覆盖、复杂度分析、有没有优化方案。

Q1：五步答题流程（每题都照这个说出口）

复述 + 澄清。用自己话重述题目，确认输入规模、数据类型、能否重复、是否原地、返回什么。主动问边界：空输入？单元素？溢出？有环？
先给暴力解 + 复杂度。O(n²) 也行，证明思路通，并说清瓶颈在哪。这一步让你有东西可写，也给面试官一个纠偏的机会。
给优化思路。说清用哪种结构降复杂度：哈希表降查找、双指针降嵌套、堆取 TopK、单调栈处理「下一个更大」。
写代码前先说结构。变量含义、循环不变量、终止条件。说完再写，面试官能跟上。
写完自测。最小用例 + 边界用例 + 一个反例，然后报时间复杂度/空间复杂度。

Q2：母题与常见变种（背母题，不背题解）

数组 / 哈希

两数之和 → 三数之和（排序+双指针+去重）、和最接近、子数组和为 K（前缀和+哈希）、允许重复。关键：去重逻辑与前缀和转化。

滑动窗口

最长无重复子串、最小覆盖子串、窗口内最大值（单调队列）。关键：何时扩窗口、何时缩、窗口内用什么结构维护。

链表

反转（区间 / 成组 K 个）、环检测与入口、两链表相交、复制带随机指针。关键：虚拟头节点、快慢指针、改指针前先存 next。

二叉树

层序变种（每层右视图 / 之字形）、路径和、序列化与反序列化、最近公共祖先。关键：递归函数返回什么信息。

动态规划

背包变种、股票买卖（冷冻期 / 手续费 / 限次数）、编辑距离、最长递增子序列。关键：状态定义 > 转移方程；一维滚动优化空间。

堆 / TopK

数据流第 K 大、前 K 个高频词、合并 K 个有序链表、滑动窗口中位数（双堆）。关键：小顶堆维持大小 K。

二分

旋转数组找最小值、找峰值、答案二分（最小化最大值 / 最大化最小值，如「运货问题」「分割数组」）。关键：单调性证明 + 边界写法统一。

图

拓扑排序（课程表）、岛屿数量（并查集 / DFS）、最短路径（BFS 无权 / Dijkstra 非负权）。关键：访问标记打上的时机。

Q3：边界清单（每题写完过一遍）

空数组 / 空字符串 / null；单元素；全部相同；已排序 / 完全逆序；含负数 / 含 0 / 极大值溢出（用 long）；重复值（去重是否要求稳定）；下标越界与切片边界；递归栈深度（链表或树退化成链时）。

Q4：题目被「加强」了怎么答

数据流版 / 在线版：不能回头扫 → 堆、单调队列、哈希 + 增量维护。说清「我只维护必要状态」。
内存受限版：不能全量加载 → 分块 + 外部排序；或概率结构（布隆过滤器、HyperLogLog、Count-Min Sketch），并主动说明「允许误差、误差界是 ε」。
并发版：先划分无共享分片 → 各分片独立处理 → 最后归并；要全局有序就用分段锁或单写多读。
分布式版：哈希分片 → 局部 TopK/聚合 → 全局归并；主动提数据倾斜（热点 key 加盐打散、二次聚合）。
示范回答（TopK 加强版）：「单机内存够就用小顶堆 O(n log k)；如果每天上亿条且内存受限，我会先按哈希分片到多台各算 TopK，再汇总取全局 TopK，并注意热门 key 的倾斜——加盐打散后二次聚合。」

Q5：卡住时的话术

不要说「让我想想」然后沉默。先说当前思路和卡在哪：「我打算用滑动窗口，但这里重复元素导致左边界不好确定，我在想用哈希记录最后出现位置。」——面试官通常会顺着你的卡点给提示，接住提示继续推进就是加分。写错了主动改口，「这里应该取 max 而不是 min」比被指出好。
