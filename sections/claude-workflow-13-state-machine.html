Claude Code Agent 的工作流状态机包含哪几种核心状态？状态如何流转？

源码里没有一个显式 WorkflowState enum，但 query.ts 的 State 和 while(true) 就是实际状态机。

Input Accepted：用户输入、队列 prompt、task notification 被接收。
Context Build：取 compact boundary 后消息，做 snip、microcompact、collapse、autocompact。
Model Streaming：调用 deps.callModel()，收 assistant text/thinking/tool_use。
Tool Decision：有 tool_use 就执行工具；没有 tool_use 就进入收尾。
Tool Execution：用 StreamingToolExecutor 或 runTools() 执行工具。
Attachment Injection：注入 queued commands、task notifications、memory、skills、file-change attachments。
Continue：把 assistantMessages + toolResults 写回 state，turnCount++，回到 Context Build。
Terminal：completed、max_turns、aborted、prompt_too_long、hook_stopped 等终止。

State 保存什么

messages、toolUseContext、compact tracking、max output token recovery、stop hook 状态、turnCount、pending tool summary、transition reason。

状态怎么跳

不是 switch enum，而是构造 next: State 后 continue；终止时 return { reason: ... }。

START -> CONTEXT_PREPARE -> MODEL_STREAMING
  -> has tool_use ? TOOL_EXECUTION -> ATTACHMENTS -> UPDATE_STATE -> CONTEXT_PREPARE
  -> no tool_use ? STOP_HOOKS / RECOVERY -> COMPLETED

边界分支：prompt_too_long、max_output_tokens、aborted_streaming、aborted_tools、max_turns、hook_stopped
