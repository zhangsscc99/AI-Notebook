Q1

如何设计一个量化 Agent

量化 Agent 的核心不是让大模型直接预测涨跌，而是把它放在研究编排层：LLM 负责提出问题、解释结果和选择工具，行情、因子、回测、风控与下单必须由确定性程序完成。

最小闭环：Point-in-time 数据 → 特征与标签 → 策略假设 → 可审阅代码 → 回测（含手续费、滑点、停牌）→ 样本外与滚动验证 → 模拟盘 → 风控闸门 → 实盘执行 → 全链路日志。

关键设计原则

LLM 只做编排

模型输出结构化 JSON 和工具调用计划，不直接持有账户权限，也不能跳过人工确认。

研究与资金隔离

回测、模拟盘、实盘使用不同环境；实盘必须经过仓位、亏损、回撤和熔断规则。

数据必须可复现

固定数据快照、时间点、代码版本和参数，防止未来函数、幸存者偏差与隐性过拟合。

评估不能只看收益

同时关注 Sharpe、最大回撤、换手率、容量、成本敏感性和样本外稳定性。

落地顺序：先做只建议不交易的 Research Copilot，再加入纸面交易，验证稳定后才开放受控实盘。
