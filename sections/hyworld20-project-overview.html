HY-World 2.0 项目概览

HY-World 2.0 是腾讯混元开源的多模态 3D 世界模型项目。它不是“生成一段看起来像 3D 的视频”，而是把文本、单张图、多视角图片或视频变成可长期保存、可编辑、可导入引擎的 3D 世界资产，主要输出形态包括 3DGS / Gaussian Splatting、mesh、点云、深度、法线和相机参数。

一句话：HY-World 2.0 的核心目标是“生成或重建一个可导航的真实 3D 世界”，而不是只生成像素视频。它把全景图生成、轨迹规划、世界扩展、3DGS/mesh 组合、视频/多图重建串成一条工程 pipeline。

1. 项目有两条主线

README 里把项目分成两个核心能力：World Generation 和 World Reconstruction。

  • World Generation：文本或单图 → 360° panorama → 可导航 3D 世界。
  • World Reconstruction：多视角图片或视频 → 3D reconstruction / digital twin。

所以它同时覆盖“从想象生成世界”和“从真实拍摄重建世界”。

整体架构：从输入到 3D 世界

README 里的 World Generation 架构是四阶段；源码又把后半段拆成五个脚本执行：

HY-Pano 2.0：全景生成。hyworld2/panogen/pipeline.py 用 HunyuanImage-3 后端，把输入图片/提示词扩展成 360° equirectangular panorama。
WorldNav：轨迹规划。hyworld2/worldgen/traj_generate.py 结合 VLM、导航网格和语义目标，规划环绕、探索、重建、上升等相机路线。
Trajectory Rendering：轨迹渲染。traj_render.py 沿规划好的轨迹渲染点云/深度/相机结果，并为后续视频扩展提供条件。
WorldStereo 2.0：世界扩展。video_gen.py 加载 WorldStereo，用 diffusion/video 模型沿轨迹生成关键帧；PanoramaMemoryBank 负责跨轨迹检索参考，减少风格和几何漂移。
World Composition：3DGS 组合。gen_gs_data.py 准备训练数据，world_gs_trainer.py 优化 Gaussian Splatting，并可导出 .ply、.spz 和 mesh。

HY-Pano 2.0 是什么

hyworld2/panogen/README.md 里说明它有两个 backend：完整的 HunyuanImage-3 pipeline 和更轻的 Qwen-Image-Edit backend。默认任务是把普通图像扩展成 360° 全景图。

pipeline.py 里有 HunyuanPanoPipeline，默认模型目录是 tencent/HY-World-2.0/HY-Pano-2.0，推理后还会做左右边缘 circular blend，保证全景图接缝更自然。

WorldStereo 2.0 是什么

hyworld2/worldgen/README.md 把 WorldStereo 2.0 定位成扩展 panoramic scene 的 diffusion-based video generation model。源码入口是 video_gen.py，它加载 WorldStereo.from_pretrained("hanshanxue/WorldStereo")。

它不只是“补视频帧”，还接收相机轨迹、点云渲染、参考全景记忆等条件，目的是沿规划路径生成一致的新视角。

WorldMirror 2.0 是什么

hyworld2/worldrecon/pipeline.py 里的 WorldMirrorPipeline 用于多图/视频到 3D 重建。底层模型 WorldMirror 在 hyworldmirror/models/models/worldmirror.py。

模型主干是 VisualGeometryTransformer，再接多个 head：CameraHead 预测相机，DPTHead 预测深度/法线/点，GSFeatHead 和 renderer 处理 3DGS。

3DGS / mesh 输出怎么来

world_gs_trainer.py 是最终世界组合和优化入口。它使用 gsplat rasterization、SSIM/LPIPS、depth loss、normal loss、sky-depth regularization、MaskGaussian pruning 等训练 Gaussian Splatting。

最终资产可以用于实时查看，也能转 ply、spz，并通过 TSDF/mesh export 进入更传统的 3D 资产流程。

为什么它不是普通视频生成模型

HY-World 2.0 和 Wan / Sora / Genie 这类视频模型最大的差别是输出目标不同：

视频生成

输出是一段像素序列。你可以看，但每一帧只是图像；换视角、碰撞、物理交互、导入游戏引擎都很难。

HY-World 2.0

输出是持久 3D 资产。场景可以被导航、编辑、渲染、导入 Unity / Unreal / Blender / Isaac Sim。渲染成本主要发生在生成完成后的一次性 3D 表示上，而不是每次交互都重新生成视频。

输入：一张室内照片，或者一句“未来城市街区”

HY-World 2.0 不是直接输出 mp4：
  1. 先生成/获得 360° panorama
  2. 规划可以走的相机路线
  3. 沿路线生成缺失的新视角
  4. 把多视角图像、深度、法线、相机组织成 3DGS 训练数据
  5. 优化成一个可以实时渲染、导航和导出的 3D 世界
最短总结：HY-World 2.0 = HY-Pano 2.0 全景生成 + WorldNav 轨迹规划 + WorldStereo 2.0 世界扩展 + WorldMirror 2.0 重建/几何预测 + 3DGS/mesh 资产组合。它的关键价值是把 AIGC 从“生成视频”推进到“生成可交互的 3D 世界资产”。
