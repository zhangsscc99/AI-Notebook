底层后端：builtin 与 qmd

builtin

默认内建方案。核心是 SQLite + FTS + 可选向量检索。

qmd

更强的 sidecar 路线，支持 collections、sessions、paths、update policy 等。

packages/memory-host-sdk/src/host/backend-config.ts
if (backend !== "qmd") {
  return { backend: "builtin", citations };
}
// else build qmd config
