Wan 怎么控制不同帧之间的时序一致性

视频生成最容易出的问题是帧间闪烁、主体漂移、动作断裂、前后物体不一致。Wan2.2 控制时序一致性不是靠某个简单的“防闪烁开关”，而是从数据表示、网络结构、位置编码、注意力范围、VAE 编解码和采样过程一起做约束。

一句话：Wan2.2 不是逐帧单独生成图片再拼成视频，而是把整段视频 latent 当成一个 F × H × W 的时空张量一起建模；Transformer token 之间可以跨帧 self-attention，RoPE 明确告诉模型每个 token 属于哪一帧，VAE 用 3D causal conv 保持时序连续，scheduler 每一步整体更新整段 latent。

可以按 6 层理解它怎么压住时序一致性：

第一层：不是逐帧生成，而是整段 latent 一起生成。WanT2V.generate() 初始化的 target_shape 是 [C, F_latent, H_latent, W_latent]。也就是说，模型一开始就拿到整段视频 latent，而不是第 1 帧生成完再独立生成第 2 帧。
第二层：3D patch embedding 保留时间维。WanModel 用 nn.Conv3d 做 patch embedding，输入是视频 latent 的 C/F/H/W。它切出来的是时空 patch token，不是单张图片 token。
第三层：self-attention 跨帧混合信息。WanSelfAttention 对 patch token 做 attention。默认配置 window_size=(-1,-1)，表示不是滑窗局部注意力；同一个视频序列里的不同帧 token 可以互相影响，模型能同时看前后帧来决定当前帧怎么动。
第四层：视频 RoPE 标注帧、高、宽三维位置。rope_apply() 把频率拆给时间 F、高 H、宽 W 三个维度。这样模型不只知道“这是第几个 token”，还知道“这是第几帧、哪个空间位置”。
第五层：VAE 不是纯 2D 图片解码器。vae2_1.py / vae2_2.py 里大量使用 CausalConv3d、downsample3d、upsample3d。VAE decode 时会在时间维做卷积/上采样，让相邻帧共享局部时序信息。
第六层：每个 denoising step 整体更新全视频。采样循环里，scheduler 不是更新某一帧，而是用模型预测结果整体更新 latents[0]。所以主体、背景、运动轨迹在每一步都作为一个全局视频状态被共同修正。

为什么“整体 latent”很关键

如果逐帧生成，每一帧都有自己的随机性，人物脸、衣服纹理、背景位置容易漂。Wan2.2 的随机噪声是整段视频 latent，后续每一步也是整段视频一起去噪；这让模型能学“一个主体在连续时间里的变化”，而不是学“很多独立图片”。

self-attention 怎么帮时序一致

attention 让第 t 帧的 token 可以读取第 t-1、t+1 或更远帧的 token。这样模型在预测当前 token 时，不只看当前局部纹理，还能参考前后帧的主体位置、姿态、背景结构，从而减少跳变。

RoPE 为什么重要

只有 attention 还不够，模型还必须知道 token 的时空坐标。rope_apply() 根据 grid_sizes=(F,H,W) 构造时间、高、宽三套旋转位置编码，给跨帧 attention 提供“时间距离”和“空间位置”的坐标感。

VAE 对一致性有什么影响

如果 VAE 按单帧独立 decode，即使 latent 稳，像素层也可能闪。Wan 的视频 VAE 用 3D causal conv 和时间上/下采样，在像素重建时也利用邻近帧信息，降低解码阶段的帧间不连续。

源码链路可以这样对上：

1. text2video.py
   target_shape = [z_dim, F_latent, H_latent, W_latent]
   noise = torch.randn(target_shape)

2. model.py / WanModel.forward()
   patch_embedding = Conv3d(...)
   grid_sizes = [F_patch, H_patch, W_patch]
   latent video -> flatten 成时空 token 序列

3. model.py / rope_apply()
   对 F/H/W 三个维度分别加 RoPE

4. model.py / WanAttentionBlock
   self-attention：视频 token 之间建模
   cross-attention：视频 token 读取文本条件

5. text2video.py 采样循环
   每个 timestep 整体更新整段 latents[0]

6. vae2_1.py / vae2_2.py
   CausalConv3d + temporal downsample/upsample
   clean latent -> 连续视频帧

和“图片模型逐帧生成”本质差异

图片模型逐帧生成通常只能靠 prompt、seed、上一帧条件或后处理来维持一致性。Wan2.2 这种视频 DiT 是原生视频建模：训练目标和网络输入就是一段视频 latent，所以时序一致性是模型能力的一部分。

它能不能保证绝对不闪

不能。长视频、复杂运动、遮挡、人物细节、文字和手部仍可能漂移。原因是 latent 压缩有损、attention 长序列建模有限、采样有随机性，且 prompt 本身可能约束不足。工程上通常还会通过更强条件、参考图、pose、低 guide scale 调参、更多步数或后处理继续改善。

最短记忆：Wan 的时序一致性 = 整段视频 latent 一起去噪 + 3D patch + 跨帧 attention + F/H/W RoPE + 视频 VAE 3D 卷积。它不是把 81 张图片分别画好再拼接，而是在一个统一的时空 latent 里生成“会动的一段视频”。
