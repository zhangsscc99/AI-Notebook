Wan2.2 项目概览

Wan2.2 是 Wan-Video 开源的大规模视频生成模型工程仓库，源码已 clone 到服务器：/root/Wan2.2。它覆盖文本生成视频、图像生成视频、文本+图像统一生成视频、语音驱动视频、人物动画/替换等多条视频生成任务线。

一句话：Wan2.2 是一个开源视频扩散模型推理框架：用 T5 编码文本条件，用 VAE 在视频 latent 空间压缩/解码，用 DiT/WanModel 做 flow-matching denoising；A14B 系列用高噪声/低噪声两个 expert 做 MoE 分段去噪，TI2V-5B 用高压缩 VAE 降低 720P 推理成本。

1. 仓库支持哪些模型/任务

README.md 和 wan/configs/__init__.py 里列出的核心任务包括：t2v-A14B 文本到视频、i2v-A14B 图像到视频、ti2v-5B 文本/图像统一到视频、s2v-14B 语音到视频、animate-14B 角色动画和替换。

2. A14B 的核心：分段 MoE 去噪

T2V/I2V A14B 配置里有 low_noise_checkpoint 和 high_noise_checkpoint。源码 WanT2V._prepare_model_for_timestep() 会根据 timestep 和 boundary 选择高噪声 expert 或低噪声 expert。

这不是 token 级 router 的 MoE，而是按扩散去噪阶段切 expert：早期高噪声阶段管整体布局，后期低噪声阶段管细节 refinement。

3. 5B TI2V 的核心：高压缩 VAE

wan_ti2v_5B.py 使用 Wan2.2_VAE.pth，vae_stride=(4,16,16)，默认 sample_fps=24、frame_num=121。README 也强调 TI2V-5B 支持 720P@24fps，并可在 4090 级别消费卡上运行。

4. 入口：generate.py

generate.py 是统一命令行入口。它解析 --task、--size、--ckpt_dir、--prompt、--image、--audio、采样步数、CFG scale、FSDP/Ulysses 等参数，然后按任务创建对应 pipeline。

从源码看，一次生成大致是下面这条链路：

参数校验。_validate_args() 检查任务是否在 WAN_CONFIGS 中，填充默认 prompt、image、audio、sample_steps、sample_shift、guide_scale、frame_num。
可选 prompt extension。如果启用 --use_prompt_extend，会用 DashScope 或本地 Qwen 扩写 prompt；T2V 用文本 Qwen，I2V 可用 Qwen-VL。
创建 pipeline。根据 task 创建 WanT2V、WanI2V、WanTI2V、WanS2V 或 WanAnimate。
条件编码。T2V/TI2V/I2V 都会用 T5EncoderModel 编码正向 prompt 和 negative prompt；S2V 额外加载 AudioEncoder / wav2vec；Animate 额外用 CLIP 和预处理过的人体/pose/face/mask 条件。
latent 初始化。根据目标分辨率、帧数、VAE stride 和 patch size 计算 latent shape / seq_len，然后用随机噪声初始化视频 latent。
flow matching 采样。使用 FlowUniPCMultistepScheduler 或 FlowDPMSolverMultistepScheduler，逐 timestep 调 WanModel 预测噪声/速度，并做 classifier-free guidance。
MoE expert 切换。A14B 在每个 timestep 根据 boundary 选择 high-noise 或 low-noise 模型；guide scale 也可按高/低噪声阶段分别设置。
VAE 解码保存。采样完成后用 VAE decode latent 成视频张量，save_video() 写成 mp4；S2V 还会把生成视频和输入/合成音频 merge。

WanModel 是什么结构

wan/modules/model.py 里的 WanModel 是视频 DiT backbone。它用 Conv3d 做 3D patch embedding，把 latent video 切成时空 patch token；用 sinusoidal time embedding 表示 diffusion timestep；用 Transformer blocks 做 self-attention 和 text cross-attention。

时空位置怎么建模

源码有 rope_params() 和 rope_apply()，把 RoPE 分到帧、高、宽三个维度上。grid_sizes 保存每个样本的 latent 时空网格，attention 时按视频 token 的 F/H/W 位置加旋转位置编码。

多卡推理怎么做

仓库支持 --t5_fsdp、--dit_fsdp 和 --ulysses_size。FSDP 用于切 T5/DiT 参数；Ulysses/sequence parallel 会替换 block self-attn forward 和 model forward，降低长视频 token 序列的显存压力。

显存优化怎么做

命令行提供 --offload_model、--convert_model_dtype、--t5_cpu。A14B 的 _prepare_model_for_timestep() 还会在 offload 模式下把当前不用的 expert 放回 CPU，只把当前 timestep 需要的 expert 放到 GPU。

各任务可以这样理解：

T2V-A14B

文本到视频 MoE 模型，支持 480P 和 720P。配置：40 层、hidden dim 5120、40 heads、Wan2.1 VAE stride (4,8,8)、默认 81 帧、16fps。

I2V-A14B

图像到视频 MoE 模型。输入图像会作为条件，输出视频的 aspect ratio 跟随输入图像；同样使用 high/low noise expert。

TI2V-5B

统一 T2V/I2V 的 5B dense 模型。是否传 --image 决定走 image-to-video，否则走 text-to-video；重点是高压缩 Wan2.2 VAE 和 720P@24fps。

S2V / Animate

S2V 用参考图、音频和可选 pose video 生成音频同步视频，可集成 CosyVoice TTS。Animate 用预处理后的 pose/face/background/mask 等材料做角色动画或人物替换。

最短总结：Wan2.2 = 视频生成大模型的完整推理工程。它的关键不是一个单文件 demo，而是“配置系统 + 多任务 pipeline + T5 条件编码 + VAE latent 压缩 + WanModel/DiT denoising + MoE expert 切换 + FSDP/Ulysses/CPU offload”的组合。
