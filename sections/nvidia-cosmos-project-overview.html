NVIDIA Cosmos 项目概览

NVIDIA Cosmos 是 NVIDIA 面向 Physical AI 的世界基础模型（World Foundation Model, WFM）平台。它的目标不是生成普通娱乐视频，而是给机器人、自动驾驶、仿真、具身智能等系统生成或延展可用于视觉仿真的世界视频，让开发者更快构造训练、评测和仿真数据。

一句话：Cosmos 是“物理 AI 的视频世界模型工具箱”：里面有 diffusion-based Text2World / Video2World、autoregressive Video2World、视频 tokenizer、prompt upsampler、guardrail 安全过滤，以及基于 NeMo 的后训练脚本。它输出的主要是高分辨率世界视频/未来帧，不是像 HY-World 那样直接组合 3DGS/mesh 资产。

2. 它解决什么问题

Cosmos 主要服务 Physical AI：机器人、自动驾驶、仓储、工业场景这些系统需要大量视频世界数据来训练和评测。真实采集昂贵，仿真又经常不够真实，所以 Cosmos 提供可控的世界视频生成能力。

例如：给一段机器人仓库视频，模型可以继续生成未来若干帧；给一段驾驶场景视频和文字条件，模型可以生成后续世界变化。

核心模块：Cosmos 不是一个单模型，而是一组世界模型组件

Diffusion WFM

cosmos1/models/diffusion 提供 diffusion-based world foundation models，支持 Text2World 和 Video2World。入口脚本是 inference/text2world.py 和 inference/video2world.py。

源码里的 DiffusionText2WorldGenerationPipeline / DiffusionVideo2WorldGenerationPipeline 会做 prompt guardrail、prompt upsampling、T5 text embedding、diffusion 采样、tokenizer 解码和输出视频安全检查。

Autoregressive WFM

cosmos1/models/autoregressive 提供自回归世界模型，主要用于从图片或短视频上下文继续生成未来视觉世界。README 里列了 Base 和 Video2World 两类模型：4B/12B base，以及 5B/13B Video2World。

源码里的 ARBaseGenerationPipeline 先把输入视频 tokenize 成离散/连续视觉 token，再用 AR model 生成后续 token，最后可走 diffusion decoder 增强画质。

Cosmos Tokenizer

cosmos1/models/tokenizer 是核心底座。它把图片/视频压缩成 continuous latents 或 discrete tokens。README 里明确支持 image/video、continuous/discrete 四类 tokenizer。

视频 tokenizer 可做空间 8x 或 16x 压缩、时间 4x 或 8x 压缩。没有 tokenizer，后面的 diffusion / autoregressive 大模型就很难直接在原始像素视频上高效训练和推理。

Guardrail

cosmos1/models/guardrail 提供安全系统，分为 pre-Guard 和 post-Guard。pre-Guard 检查输入 prompt，包括 blocklist 和 Aegis；post-Guard 检查生成视频，包括 Video Content Safety Filter 和 Face Blur Filter。

这不是外围文档功能，而是集成在 diffusion 和 autoregressive pipeline 里的实际步骤。

Prompt Upsampler / Text Encoder

Diffusion pipeline 里有 prompt upsampler。Text2World 会把短 prompt 扩写成更丰富的描述；Video2World 会用视觉输入生成/增强 prompt。随后 CosmosT5TextEncoder 把文本转成条件 embedding。

所以 Cosmos 里用了语言模型/视觉语言模型，但它们主要是 prompt 增强和条件构造，不是最终的视频世界生成主干。

NeMo 后训练

cosmos1/models/POST_TRAINING.md 和各模块 nemo/post_training 目录提供后训练路线，用 NVIDIA NeMo 对 diffusion 或 autoregressive WFM 做下游 Physical AI 场景适配。

这说明 Cosmos 不只是 demo 推理仓库，也给了继续训练、领域适配和数据准备的工程入口。

Diffusion Text2World / Video2World 的典型流程

输入。Text2World 接收文本 prompt；Video2World 接收图片/视频条件，必要时也接收文本 prompt。
安全检查。BaseWorldGenerationPipeline 先跑 text guardrail；生成后还会跑 video guardrail。
Prompt upsampling。短 prompt 会被扩写成更详细的影视级描述；Video2World 的 upsampler 会结合视觉输入生成描述。
文本条件编码。CosmosT5TextEncoder 把 prompt 编成 embedding，给扩散模型做条件。
世界 latent 生成。generate_world_from_text() 或 generate_world_from_video() 在 latent 空间里采样生成视频世界表示。
Tokenizer 解码。self.model.decode(sample) 把 latent 解码成 [T,H,W,C] 视频帧。
输出过滤。post-Guard 对输出视频做安全分类和人脸模糊，安全才返回最终视频。

Autoregressive Video2World 的典型流程

输入图片 / 9 帧短视频 / 可选文本 prompt
  → Cosmos video tokenizer 编码成视觉 token
  → AR model 根据上下文 token 预测未来 token
  → diffusion decoder 可选增强生成结果
  → tokenizer / decoder 还原为视频帧
  → video guardrail 安全过滤
  → 输出未来世界视频

这条线更接近“给世界一个开头，让模型继续往后推演”。源码中 generate_partial_tokens_from_data_batch() 负责从输入上下文生成后续 token；diffusion_decoder_process_tokens() 负责把 AR token 结果进一步增强成更高质量的视频。

和 HY-World 2.0 的关键区别

Cosmos 更像视频世界基础模型

它重点输出视频世界：Text2World、Video2World、未来帧延展、物理 AI 仿真视频。核心表示是视频 latent / visual token / generated frames。

HY-World 更像 3D 世界资产 pipeline

HY-World 2.0 会把全景、轨迹、新视角、深度、法线、相机、3DGS/mesh 串成可导航的 3D 资产。Cosmos 公开源码重点不是 3DGS/mesh 组合，而是世界视频生成模型。

最短总结：NVIDIA Cosmos 是面向机器人/自动驾驶等 Physical AI 的世界视频基础模型平台。它的工程核心是：视频 tokenizer 降低建模成本，diffusion 和 autoregressive 两条生成路线负责世界视频生成，prompt upsampler/T5 提供语言条件，guardrail 管安全，NeMo 支持后训练。
