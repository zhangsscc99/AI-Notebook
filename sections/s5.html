真正干活的核心对象：MemorySearchManager

memory 子系统真正的统一控制器是 MemorySearchManager。

packages/memory-host-sdk/src/host/types.ts
interface MemorySearchManager {
  search(...)
  readFile(...)
  status()
  sync?(...)
  probeEmbeddingAvailability()
  probeVectorAvailability()
  close?()
}

你可以把它理解成：索引、搜索、读取、健康检查、资源回收全部都要经过这个抽象层。

参考：packages/memory-host-sdk/src/host/types.ts:85-110
