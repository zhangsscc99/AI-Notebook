详解这个训练里的损失函数

这次 FastApply 训练用的不是监督学习的 cross entropy，而是 MinT 的 loss_fn="importance_sampling"。它对应 GRPO / policy-gradient 风格更新：同一个 prompt 采样多条 response，用 verifier reward 算组内 advantage，然后让高 advantage 轨迹概率上升、低 advantage 轨迹概率下降。

Datum 里四个核心输入

  • target_tokens：当前序列每个位置要预测的下一个 token。
  • weights：prompt 部分为 0，response 部分为 1，只训练生成段。
  • logprobs：采样时旧策略 π_old 对生成 token 的 log probability。
  • advantages：同组 reward 中心化后的相对优势，复制到 response 每个 token。

直观公式

reward_i = verifier(output_i)
adv_i = reward_i - mean(reward_group)
ratio_t = exp(logπ_new(token_t) - logπ_old(token_t))
loss ≈ - Σ weights_t · adv_i · ratio_t

所以 advantage 为正时，模型被推动提高这条输出的概率；advantage 为负时，模型被推动降低这条输出的概率。

采样：用当前 LoRA sampler 生成 candidate updated code。
打分：检查 exact match、tag 格式、是否有多余文本、语法合法性。
中心化：同组内 reward 减均值，得到 advantage。
importance sampling：用旧 logprob 和新 logprob 的 ratio 做离策略校正。
精髓：这个 loss 学的不是“标准答案 token 长什么样”，而是“在这一组采样里，哪条生成轨迹更值得提高概率”。这就是 GRPO 和普通 SFT 的根本区别。
本次报告中：policy rollout reward=0.95、advantage=-0.025；oracle rollout reward=1.0、advantage=+0.025；loss:mean=0.0001722524906026906。
