UML 图怎么画：记号速查 + 完整示例

西门子笔试明确要求画 UML。这篇把面试要用的记号一次讲全：类图六种关系、可见性、构造型，时序图生命线/激活条/组合片段，每个都配正确渲染的图。

面试最常考两种图：类图（Class Diagram）画静态结构，时序图（Sequence Diagram）画交互流程。用例图、活动图了解即可。

一、类图基础：一个类框的三格

类框从上到下三格：类名（抽象类用斜体，接口标 «interface»）→ 属性 → 方法。成员前的符号是可见性：

+ public

对外公开，谁都能调。

- private

仅类内部，封装细节的默认选择。

# protected

自己和子类可见，为继承留的口子。

~ package

同包可见（Java 默认），很少考。

下划线成员 = static；方法名斜体 = 抽象方法；«构造体»（stereotype）标注特殊角色如 «interface» «abstract» «entity» «strategy»。

二、六种关系：箭头是笔试给分点

三、综合示例：电商下单类图（六种关系全用上）

Order ◆— OrderLine 组合（订单没了明细也没了）；Customer —→ Order 关联；VipMember —▷ Customer 继承；Alipay/Wechat ┄▷ PaymentStrategy 实现；Order —→ PaymentStrategy 关联注入（策略模式）；OrderService ┄→ Order «use» 依赖（只在 checkout 里临时构造）。

四、时序图：五个记号就够

生命线 Lifeline

顶部对象框 + 向下虚线，表示参与者存活时间。

激活条 Activation

生命线上的窄矩形，表示该对象正在执行。

消息箭头

实线实心箭头 = 同步调用；虚线开箭头 = 返回；实线开箭头（或三角标 async）= 异步。

组合片段

方框角标：alt（分支）、opt（可选）、loop（循环）、ref（引用别的图）。

五、其他图一句话记住

用例图：小人（Actor）— 椭圆（用例），只回答"谁用什么功能"；活动图：带泳道的流程图，圆点起始、牛眼结束、菱形分支；状态图：圆角矩形状态 + 箭头迁移，适合讲订单/连接生命周期；组件图：方块 + 棒棒糖/插座接口，表达模块依赖。

六、笔试答题套路

先画 3-5 个核心类框：名字 + 1-2 个关键方法即可，属性可以只写最重要的——粗粒度策略，细节留口头。
把关系箭头画对：这是阅卷点。拿不准就用关联（实线箭头）兜底，比画错菱形强。
时序图编号消息：1、2、3…按时间标号，面试官一眼能按序追问。
主动说取舍："这里我用了组合而不是聚合，因为 OrderLine 生命周期依附 Order"——一句话把记号变成设计理由。
