搜索一次 memory，大概发生了什么

先检查有没有索引；没有就尝试 sync。
做 query 预处理与 preflight。
如果需要，初始化 embedding provider。
跑 keyword / vector / hybrid 检索。
做 merge、score、filter，然后返回结果。
extensions/memory-core/src/memory/manager.ts
async search(query, opts) {
  if (!hasIndexedContent) await sync(...)
  const preflight = resolveMemorySearchPreflight(...)
  if (preflight.shouldInitializeProvider) await ensureProviderInitialized()
  ... run search ...
}
这就是为什么 memory search 不是“grep 一下文本”——它其实是带索引、带 provider、带 fallback 的完整 retrieval pipeline。
