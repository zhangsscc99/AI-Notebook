72 张图 RL-master FastApply GRPO 源码迁移报告

这次按 /root/rlhf/images 里的 72 张参考图，把 RL-master / verl 风格 FastApply GRPO pipeline 迁移到当前训练项目。核心不是 SFT，而是 data → rollout(n=8) → reward → group advantage → policy/KL/entropy loss → update 的 GRPO 闭环。

新增源码入口

  • rl_master/configs/config-rl-fastapply.yaml：复刻图里的 rollout batch、seq_len=8192、n=8、temperature/top_p=0.99、top_k=50、GRPO advantage 配置。
  • rl_master/scripts/run_fastapply_grpo_smoke.py：离线可跑的 8-rollout GRPO smoke，输出逐样本 reward、advantage、policy loss、KL loss、entropy bonus。
  • rl_master/scripts/run_fastapply_ver1.py：FastApply 环境 + rule reward smoke。
  • fastapply_pipeline/train_mint_fastapply_grpo.py：真实 MinT Qwen3 4B LoRA GRPO 入口，使用 loss_fn="importance_sampling"。

图片模块迁移范围

  • 1–18：训练脚本、配置、rollout、GRPO loss 总览。
  • 19–30：score.py、utils.py、FastApply environment，reward = 0.8 correctness + 0.2 validity。
  • 32–37：apply.yaml、generate.yaml、judge.yaml prompt 协议。
  • 38–56：extractor、evaluation strategy、agent、pipeline、evalfastapply。
  • 57–72：LLM wrapper、Inference、PromptTemplate、JSON / pattern parser 支撑层。
采样。同一个 FastApply prompt 生成 8 条候选 updated code，真实训练用 Qwen3 4B sampler；离线 smoke 用确定性候选复刻字段。
奖励。先 rule exact compare（忽略空白行），失败再走 judge prompt；环境层按 0.8 * correctness + 0.2 * validity 聚合。
优势。同组 reward 做标准化：adv_i = (reward_i - mean) / std，高分样本为正，低分样本为负。
损失。policy surrogate 用新旧 logprob ratio 与 advantage；再加 ref KL 惩罚，减 entropy bonus；真实 MinT 入口对应 importance_sampling。
