Claude Code 中，工作流编排和任务规划（广义 agent 任务规划）的核心差异是什么？

这里的任务规划不是 Claude Code 的 Plan Mode，而是广义 agent planning：模型如何拆目标、排步骤、选择工具。它和工作流编排不是一回事。

核心区别：任务规划是模型层“想做什么、先做什么”；工作流编排是运行时层“如何安全执行、记录、恢复，并把结果送回模型”。

任务规划：认知策略层

决定先读哪些文件、是否搜索、要不要派 Explore agent、先改哪层代码。它体现在模型文本、TodoWrite、TaskCreate、Agent prompt 和工具选择里。

工作流编排：执行控制层

决定用户输入如何成 messages、工具如何过权限、tool_result 如何闭合、上下文太长怎么办、后台任务怎么通知、max turns 怎么终止。

规划可以变，编排必须稳

每个任务的规划都可能不同；但工具协议、权限、transcript、compact、状态流转必须稳定，否则 agent 会不可恢复或不安全。

Claude Code 的选择

不把所有任务强制塞进固定 planner-executor DAG，而是让模型动态规划，让运行时强制执行协议。

Planning：目标拆解、步骤、策略、工具选择、子任务拆分
Orchestration：schema、权限、工具执行、tool_result、attachments、compact、transcript、task notification
