DeepSeek Harness 是什么，解决什么问题

DeepSeek Harness（命令行入口 dsh）是 DeepSeek AI 开源的 Agent Harness。它不是聊天模型，而是组织模型、工具、会话、权限、工作区、插件和 agent loop 的运行环境。

一句话：DeepSeek Harness 解决的是“如何让模型可靠地完成多轮真实任务”：模型负责判断下一步，Harness 负责工具执行、状态持久化、权限边界、错误恢复和可扩展性。

让模型真正行动

通过工具与执行流水线，模型可以读取工作区、运行命令、使用终端、委托 subagent，并把观察结果继续送回 agent loop。

把任务变成可恢复状态

Session 使用追加式事件日志表达用户消息、模型请求、流式响应、工具调用和结果。模型历史从日志投影出来，而不是依赖一段不可审计的数组。

一切皆插件

模型适配器、工具注册表、会话日志、agent loop 都是可替换插件。扩展方式是在共享 context 上挂载新能力，而不是修改一个隐藏的特权核心。

面向真实运行环境

包含 Web、headless、SDK、ACP 等 profile，以及沙箱、审批、凭据、遥测和文件系统能力 seam。

它和普通聊天客户端的区别

普通客户端的核心对象是“消息”；Harness 的核心对象是“可执行任务”。一次 turn 可以包含多个 step，每个 step 都是一次模型请求及其工具调用。Harness 必须在每一步之间保存状态、执行策略、恢复失败，并把真实结果重新交给模型。
