概览介绍 Hunyuan3D-2 项目

Hunyuan3D-2 是腾讯混元开源的 3D 资产生成工程仓库，源码已 clone 到服务器：/root/Hunyuan3D-2。它的目标不是生成 2D 图片或视频，而是从输入图片生成可导出的 3D mesh，并可继续生成纹理，最后输出 glb / obj 这类 3D 资产。

一句话：混元 3D 是一个“两阶段 3D 生成系统”：第一阶段用 Hunyuan3D-DiT 做 image-to-shape，生成裸 mesh；第二阶段用 Hunyuan3D-Paint 做 texture synthesis，把参考图的外观烘焙到 mesh 的 UV 纹理上。

1. 这个项目解决什么问题

输入一张物体图片，比如玩具、角色、商品图，项目可以生成一个 3D 模型。最小 demo 里就是读取 assets/demo.png，先跑 shape generation 得到 mesh，再跑 texture generation，最后 mesh.export('demo.glb')。

2. 两个核心模型

README 明确把系统拆成两个基础组件：Hunyuan3D-DiT 是形状生成模型，负责几何结构；Hunyuan3D-Paint 是纹理生成模型，负责高质量贴图。这样把“形状”和“材质/颜色”两个难题解耦。

3. 不是文本直接生成 3D

仓库主流程是 image-to-3D。也有 hy3dgen/text2image.py，可先把文本变成图片，再把图片作为 3D 生成条件。真正的 3D 形状生成入口仍然是图片条件。

4. 主要输出是什么

形状阶段输出 trimesh.Trimesh 或 latent；纹理阶段输出带 UV/贴图的 mesh。最终可以导出 .glb，直接进 Blender、网页 3D viewer、游戏资产流程或后续 3D 编辑工具。

源码里最短的完整链路在 minimal_demo.py：

from hy3dgen.shapegen import Hunyuan3DDiTFlowMatchingPipeline
from hy3dgen.texgen import Hunyuan3DPaintPipeline

pipeline_shapegen = Hunyuan3DDiTFlowMatchingPipeline.from_pretrained('tencent/Hunyuan3D-2')
pipeline_texgen = Hunyuan3DPaintPipeline.from_pretrained('tencent/Hunyuan3D-2')

mesh = pipeline_shapegen(image=image)[0]
mesh = pipeline_texgen(mesh, image=image)
mesh.export('demo.glb')

按工程流程拆开看：

输入图片。demo 读入 RGBA 图片；如果是 RGB，先用 BackgroundRemover 抠背景，避免背景干扰物体 3D 结构。
加载 shape pipeline。Hunyuan3DDiTFlowMatchingPipeline.from_pretrained() 通过配置加载 model、vae、scheduler、conditioner、image_processor。
图片条件编码。prepare_image() 做图片预处理，encode_cond() 用 conditioner 得到条件向量；需要 CFG 时还会拼 unconditional 条件。
形状 latent 采样。pipeline 用 prepare_latents() 初始化随机 latent，然后用 flow matching scheduler 设定 sigmas/timesteps，循环调用 DiT denoiser 预测更新方向。
VAE 解码成 mesh。采样后的 shape latent 进入 ShapeVAE，再经过 volume decoding 和 surface extraction，转成可导出的 trimesh。
纹理生成。Hunyuan3DPaintPipeline 对 mesh 做 UV wrap，渲染多视角 normal/position 条件，用 multiview diffusion 生成多视角纹理图，再 bake 回 UV texture。
导出 3D 资产。纹理阶段把贴图写回 mesh，最后导出 demo.glb。

形状生成模型：Hunyuan3D-DiT

hy3dgen/shapegen/models/denoisers/hunyuan3ddit.py 里定义了 DiT denoiser。它把 shape latent 投影到 hidden size，把 timestep 编成向量，把图片条件投影进模型；然后先跑 double-stream blocks 让 latent 和 condition 交互，再跑 single-stream blocks，最后输出 latent 更新量。

形状 VAE：ShapeVAE

ShapeVAE 不是视频 VAE，而是 3D 形状 latent 和 mesh/occupancy 表示之间的桥。latents2mesh() 先做 volume decoding 得到 grid logits，再用 marching cubes / surface extractor 提取表面。

纹理生成：Hunyuan3D-Paint

hy3dgen/texgen/pipelines.py 里先做 delight 去高光/阴影，再渲染多视角 normal map 和 position map；多视角扩散模型生成各视角纹理后，bake_from_multiview() 把纹理投影回 UV 图。

模型族

README 的 model zoo 包括 Hunyuan3D-2、Hunyuan3D-2mini、Hunyuan3D-2mv、Turbo/Fast、Paint、Delight 等子模型。大模型质量更好，mini 更省资源，mv 面向多视角输入，Turbo/Fast 偏推理加速。

和 Wan2.2 视频生成对比，混元 3D 的核心差异是输出空间不同：

Wan2.2：视频 latent → 像素帧

Wan 在视频 latent 空间去噪，VAE decode 成一帧帧 RGB 视频，最后保存 mp4。它关注时序一致性、运动和画面质量。

Hunyuan3D：shape latent → mesh + texture

混元 3D 在 3D shape latent 空间生成几何，再把 surface 抽成 mesh，最后给 mesh 贴纹理。它关注几何拓扑、表面细节、UV 纹理和多视角一致性。

最短总结：Hunyuan3D-2 = 图片到 3D 资产的完整生成工程。主线是“图片条件 → DiT/flow matching 生成 shape latent → ShapeVAE 解码成 mesh → Paint 多视角生成纹理 → bake 到 UV → 导出 GLB”。
