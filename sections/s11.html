为什么 memory_get 相对安全

memory_get 不是任意文件读取器，而是一个受控的摘录工具。

  • 路径必须在允许的 memory 边界内
  • workspace 里只能读 memory 相关路径
  • extraPaths 也会做校验
  • 默认只返回有限行数和有限字符
  • 如果内容过长，会返回 continuation 提示
