FTS + vector 混合排序

builtin search 不是简单“只搜向量”。它优先做 hybrid：关键词 FTS 和向量相似度各自产生候选，然后合并、去重、加权排序。

preflight 清洗 query，并确认索引里有内容。
如果 provider 不可用，就进入 FTS-only 模式，只查 chunks_fts。
如果 provider 可用，先查 FTS 候选，再把 query embed 成向量查 vector 候选。
按 chunk id 合并结果，同一个 chunk 同时保留 vectorScore 和 textScore。
最终分数大致是：vectorWeight * vectorScore + textWeight * textScore。
之后可继续应用 temporal decay 和 MMR，让结果兼顾新近度和多样性。

FTS query 本身会把 query 里的词提取出来，构造成 quoted AND 查询；BM25 rank 会被转成 0 到 1 附近的可合并分数。

研究排序时不要只看 searchVector。真正的排序入口在 mergeHybridResults，还要看 mmr.ts 和 temporal-decay.ts。
