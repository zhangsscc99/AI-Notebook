西门子医疗一面考什么：流程、节奏与考点总览

多位候选人的反馈高度一致：西门子医疗一面是项目深挖 + 传统八股 + 英语口语三件事的组合。开场常常直接英文面，要求用英文讲 agent 项目；追问几轮后转中文继续抠项目细节；后半段进入设计模式、设计原则、并发、数据库、K8s、CNN、大模型与 RAG 设计这类标准题。

面试结构画像：① 英文自我介绍 / 英文讲项目（可能突然要求"把刚才说的用英文复述一遍"）→ ② 中文项目深挖（特别是 harness 怎么做）→ ③ 八股连发（设计模式、原则、锁、B+ 树、K8s、卷积、大模型）→ ④ 系统设计（设计一个 RAG 系统）。

考点清单（按反馈频次）

项目 / harness 怎么做 ★★★、设计模式 ★★★、英文口语（daily work、复述项目）★★★、软件设计原则 ★★、RAG 系统设计 ★★、K8s ★★、卷积原理 ★★、大模型理解 ★★、测试 ★、悲观锁/乐观锁 ★、B+ 树 ★。

面试官风格

反馈中提到"有高级别面试官"，特点是关心工程落地：不是问你概念定义，而是问"你项目里具体怎么做的"，比如 harness 怎么搭、测试怎么写、问题怎么反馈。问题很细、追问很多。

英文考察形式

两种已出现的形式：① 开场直接英文面 agent 项目；② 中文介绍到一半，突然要求"用英文把刚才的点复述一遍"。另外会要求用英文描述 daily work。所以要准备两套材料：项目英文讲稿 + daily work 英文模板。

准备策略

项目部分：能中英文各讲一遍，且每个技术点都能往下钻两层。八股部分：不需要长篇大论，但要求"定义 + 场景 + 你项目里怎么用的"三段式。系统设计：RAG 要能画出完整链路并讲清每个环节的 trade-off。

被追问时的通用回答骨架：

先给结论。一句话回答是什么/怎么做，不要绕。
给结构。分 2-4 点展开，每点一个关键词。
落到项目。"在我项目里这一点体现为……"，把八股变成经验。
留钩子。主动提一个可以深挖的点（如 harness、reward 设计），引导面试官往你准备好的方向问。
