VRAG 检索召回几个，topK 在哪里配置

默认召回数量是 topK=3，但不同入口配置位置不一样。

SearchEngine 默认

SearchEngine.search(self, queries, top_k=3) 默认 topK 是 3。代码还会做 top_k = min(top_k, len(file_data_list))，防止请求数量超过索引长度。

FastAPI 默认

search_engine_api.py 从请求 body 读取 top_k = body.get("top_k", 3)，所以 API 不传时也是 3。

VRAG demo

demo/vrag_agent.py 的 search() 写死请求 {"queries": query, "top_k": 3}。也就是说经典 VRAG demo 每次 search 默认拿 3 张候选图。

VimRAG demo

VimRAG.__init__ 的 search_top_k=3，Streamlit UI 里 Search Top-K slider 范围是 1 到 10，默认 3。注意 VimRAG 还有一个 memory top_k=5，用于多模态记忆回填，不是检索召回 topK。

结论：VRAG 当前默认检索召回 3 个候选。如果要改，API 层可以传 top_k，VimRAG UI 可调；经典 vrag_agent.py 需要改源码里的 top_k: 3。
