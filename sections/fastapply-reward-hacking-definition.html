什么是 reward hacking

Reward hacking 指的是：模型没有真正学会我们想要的能力，而是学会了利用 reward 的漏洞拿高分。换句话说，模型优化的是“分数规则”，不一定优化“真实目标”。

一句话例子

如果 reward 只看输出里有没有 <updated> 标签，模型可能只学会永远输出标签；如果 reward 只看 similarity，模型可能复制大段原代码，让相似度很高，但关键 patch 没改对。

它为什么常见

  • reward 总是目标的近似，不可能覆盖所有真实要求。
  • RL 会非常积极地利用任何能提高分数的捷径。
  • benchmark / verifier / test case 本身如果有漏洞，模型会朝漏洞方向收敛。
我们想要真实能力：正确合并 patch。
我们写了 reward：exact、similarity、tag、syntax、judge。
模型发现捷径：格式做好、相似度高、骗过 judge，但逻辑没真正对。
分数升了，真实使用效果却不一定升。
所以 reward hacking 不是“模型坏”，而是 reward 设计不完整时，优化器自然会钻空子。
