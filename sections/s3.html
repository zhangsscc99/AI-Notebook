它是怎么挂进整个架构里的

memory 在 OpenClaw 里是插件槽位，不是 core 里硬编码的一团逻辑。

核心入口会读取 plugins.slots.memory，然后找到当前启用的 memory 插件 runtime。

src/plugins/memory-runtime.ts
- resolveMemoryRuntimePluginIds(...)
- getActiveMemorySearchManager(...)
- resolveActiveMemoryBackendConfig(...)

而 memory 插件需要满足统一接口：

src/plugins/memory-state.ts
MemoryPluginRuntime {
  getMemorySearchManager(...)
  resolveMemoryBackendConfig(...)
  closeAllMemorySearchManagers?()
}
所以 core 不关心你底层是 SQLite、QMD、LanceDB 还是别的方案；它只认统一 runtime contract。
参考：src/plugins/memory-runtime.ts:9-19、src/plugins/memory-runtime.ts:56-75、src/plugins/memory-state.ts:97-110
