如何运行、接入 SDK 和扩展 Harness

DeepSeek Harness 提供多个入口：本地 Web UI、headless runner、TypeScript / Python SDK，以及自动化用的 ACP profile。第一次使用建议从 npm 包和 Web UI 开始。

最快启动

npx @deepseek-ai/dsh web

命令默认在 http://127.0.0.1:3080 启动 Web UI。通过 SSH 运行时可使用 --no-open 避免尝试打开远端浏览器。

1. 配置模型

在 Web UI 的 Settings → Models 中填写 DeepSeek API key。模型路由保存后即可使用。

2. 选择 workspace

添加并选择允许 Agent 访问的项目目录。未选择 workspace 时，部分 Web UI 操作不可用。

3. 运行任务

创建 Session，让 Agent 阅读、修改和执行。需要审批的操作遵循当前权限策略。

4. 审查变化

把 Agent 的改动当成外部变更检查：看 diff、运行测试，再决定是否保留。

从源码构建

git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web

SDK 与扩展路径

SDK 不是另一套 Agent 实现，而是通过同一 launcher 启动 sdk profile，并暴露 JSON-RPC 调用。扩展产品行为时，优先新增插件：新模型 provider 注册到 ctx.llm，模型可见能力注册到 ctx.tools，本地或远程执行环境分别实现 shell、fs、sandbox seam。

安全边界：Harness 可以执行真实命令、修改文件并调用外部工具。先阅读官方 SAFETY.zh.md，在隔离工作区中运行，并为审批、凭据和沙箱设置明确边界。
事实来源：DeepSeek Harness 官方 README、Web UI Guide 与 docs/architecture.zh.md。项目当前处于 Developer Preview。
