claude code工作流编排：总体入口

服务器上的 Claude Code 源码 zip 已解压到 /root/OpenClaw/src/claude_code_source/claude-code-source-code-main。这份源码来自 @anthropic-ai/claude-code v2.1.88 的反编译/拆包研究仓库，项目自身 README 也说明它不是完整内部源码，部分 feature-gated 模块在公开 npm 包里被裁剪。

一句话：Claude Code 的工作流编排不是单个函数，而是一条分层流水线：CLI/SDK 接收输入 → QueryEngine 管会话和 transcript → query() 驱动模型/工具循环 → tool orchestration 执行工具并回填结果 → AgentTool / coordinator 把复杂任务拆给子代理或 workers。
main.tsx / runHeadless / REPL
  -> QueryEngine.submitMessage()
  -> processUserInput(): slash command / attachment / memory / prompt
  -> query(): model streaming + tool_use loop
  -> runTools() or StreamingToolExecutor
  -> toolExecution(): hooks + permission + tool.call()
  -> tool_result returns to query()
  -> repeat until no tool_use / stop hook / compact / abort
