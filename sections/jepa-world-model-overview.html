JEPA1

概览 EB-JEPA 项目：架构、世界模型路线、和大语言模型的区别

EB-JEPA 是 Meta FAIR 开源的 Energy-Based Joint-Embedding Predictive Architecture 教学与实验库。它不是一个聊天模型项目，而是围绕“在表征空间预测未来，并用这个预测能力做规划”来组织代码：把图片/视频/环境观测编码成 latent representation，再训练 predictor 在 latent 空间预测未来状态，最后用 CEM / MPPI 这类规划器搜索动作序列。

一句话：LLM 学的是“给定文本上下文，下一个 token 是什么”；EB-JEPA 学的是“给定当前世界观测和动作，未来世界状态的表示应该是什么”。它的核心输出不是文字 token，而是未来视觉/状态 embedding，以及基于 embedding 距离定义的 planning cost。

1. 这个 repo 主要包含什么

Image JEPA / JEA

examples/image_jepa 在 CIFAR-10 无标签图片上做自监督表征学习。README 里也说明这里更像 JEA：单图增强视图之间学不变表示，核心是 encoder + projector + VICReg/SIGReg 类防坍塌损失，不强调时间预测。

Video JEPA

examples/video_jepa 用 Moving MNIST 视频序列训练模型预测未来帧的 representation。它不是直接预测像素，而是先把帧编码成 latent，再在 latent 里预测未来。

Action-Conditioned Video JEPA

examples/ac_video_jepa 是最接近“世界模型”的部分：Two Rooms 环境里，模型根据当前图像状态和动作预测下一状态表示，然后 planner 用模型想象动作后果，朝目标状态规划。

Planning 模块

eb_jepa/planning.py 实现 GCAgent、ReprTargetDistMPCObjective、CEMPlanner、MPPIPlanner。这是把 JEPA 从“会预测”变成“能规划”的关键。

2. 核心架构：Encoder + Action Encoder + Predictor + Regularizer + Prediction Cost

源码里的主类在 eb_jepa/jepa.py。JEPAbase 保存三个核心模块：observation encoder、action encoder、predictor；JEPA 再加上 regularizer 和 prediction cost 用于训练。

class JEPAbase(nn.Module):
    def __init__(self, encoder, aencoder, predictor):
        self.encoder = encoder          # observation -> latent state
        self.action_encoder = aencoder  # action -> action latent / identity
        self.predictor = predictor      # latent state + action -> future latent

class JEPA(JEPAbase):
    def __init__(self, encoder, aencoder, predictor, regularizer, predcost):
        self.regularizer = regularizer  # 防止 representation collapse
        self.predcost = predcost        # predicted latent vs target latent

训练时先把观测序列编码成 state = self.encoder(observations)，再让 predictor 预测未来 latent。loss 由两部分组成：

state = encoder(observations)
predicted_states = predictor(state, encoded_actions)
loss = prediction_loss(state, predicted_states) + regularization_loss(state)

3. Video JEPA：在 representation 空间预测未来，而不是直接生成图片

examples/video_jepa/main.py 里构建模型时很清楚：

encoder = ResNet5(cfg.model.dobs, cfg.model.henc, cfg.model.dstc)
predictor_model = ResUNet(2 * cfg.model.dstc, cfg.model.hpre, cfg.model.dstc)
predictor = StateOnlyPredictor(predictor_model, context_length=2)
regularizer = VCLoss(cfg.loss.std_coeff, cfg.loss.cov_coeff, proj=projector)
ploss = SquareLossSeq(projector)
jepa = JEPA(encoder, encoder, predictor, regularizer, ploss)

这里的关键是 StateOnlyPredictor 和 SquareLossSeq。模型不是学“像素 RGB 下一帧”，而是学“下一帧经过 encoder 后的 representation”。这样做的意义是：模型可以忽略像素级细节噪声，更多容量用于学习物体位置、运动趋势、动态规律。

4. Action-Conditioned JEPA：真正的世界模型路线

examples/ac_video_jepa/main.py 里，Two Rooms 环境使用 ImpalaEncoder 编码图像，用 RNNPredictor 根据 action 推进 latent state：

encoder = ImpalaEncoder(...)
predictor = RNNPredictor(hidden_size=encoder.mlp_output_dim, final_ln=encoder.final_ln)
aencoder = nn.Identity()
regularizer = VC_IDM_Sim_Regularizer(...)
ploss = SquareLossSeq()
jepa = JEPA(encoder, aencoder, predictor, regularizer, ploss)

这就是世界模型的最小闭环：

看世界：输入当前图像观测 s_t。
编码世界状态：z_t = Encoder(s_t)。
加入动作：输入动作 a_t，动作可以是连续控制向量。
预测未来：z_{t+1} = Predictor(z_t, a_t)，可 autoregressive unroll 多步。
规划：枚举/采样动作轨迹，选择能让预测 latent 接近目标 latent 的动作。

5. Planning 怎么做：不是让模型输出动作，而是搜索动作

eb_jepa/planning.py 里 GCAgent.set_goal() 会先把目标图像编码成目标 embedding：

self.goal_state_enc = self.model.encode(goal_state)
objective = ReprTargetDistMPCObjective(target_enc=self.goal_state_enc)
self.planner.set_objective(objective)

随后 planner 对很多候选动作序列做 rollout：

predicted_encs = self.unroll(obs_init, actions)
cost = objective(predicted_encs)

ReprTargetDistMPCObjective 的 cost 本质是 predicted encoding 和 goal encoding 的 MSE。CEMPlanner / MPPIPlanner 每轮采样一批动作轨迹，调用世界模型预测未来，把 cost 低的轨迹选出来更新分布，最后执行前几个动作。这就是“模型预测控制”：每一步重新看环境、重新规划。

6. 为什么叫 Energy-Based

这里的 energy 可以理解为“候选未来/候选动作的代价函数”。在 planning 里，某条动作轨迹经过 JEPA 预测后，如果未来 embedding 离目标 embedding 很近，它的 energy/cost 就低；反之就高。

候选动作序列 a[0:H]
  → JEPA imagined rollout: z_hat[1:H]
  → energy / cost = distance(z_hat, z_goal)
  → 选择低 energy 的动作序列

这和普通生成式模型不同：它不一定要对所有未来像素建完整概率分布，也不需要像 LLM 一样输出 token 概率；它只需要学到一个好用的表示空间和预测函数，让“好未来”和“坏未来”能被 cost 区分。

7. 和大语言模型的根本区别

LLM 路线

  • 输入输出主要是离散文本 token。
  • 训练目标通常是 next-token prediction。
  • 模型最后输出 vocab logits，再采样/解码成文字。
  • “世界知识”隐含在语言统计和语料中。
  • 做规划时常靠语言推理、工具调用、搜索或外部环境反馈。

EB-JEPA / 世界模型路线

  • 输入是图像、视频、环境状态、动作向量。
  • 训练目标是 latent prediction + 防坍塌 regularization。
  • 输出是未来状态 embedding，不是文字 token。
  • 重点学习物理/视觉动态：状态如何随时间和动作变化。
  • 做规划时直接在 learned latent dynamics 上优化动作序列。

8. 防坍塌为什么重要

JEPA 只在 embedding 空间预测，有一个典型危险：encoder 可能把所有输入都编码成同一个向量。这样 prediction loss 很低，但表示完全没信息，模型“坍塌”了。所以 repo 里用了多种 regularizer：

  • VCLoss：variance loss 保证每个特征维度有足够方差；covariance loss 惩罚特征维度之间过强相关。
  • TemporalSimilarityLoss：让同一轨迹上的相邻状态表示更平滑。
  • InverseDynamicsLoss：从连续状态表示反推 action，避免表示只记住无关背景或走捷径。

examples/ac_video_jepa/README.md 的 ablation 也强调，去掉 variance、covariance、time-sim、IDM 都会显著损害 planning success，尤其 IDM 对随机墙环境很关键。

最终理解：EB-JEPA 是一条“非语言中心”的世界模型路线。它不是把环境描述成文本再让 LLM 推理，而是把视觉世界压成 latent state，学习 latent dynamics，再用能量/代价函数做动作规划。它和 LLM 可以互补：LLM 适合语义任务分解和工具编排，JEPA 适合学习可预测的视觉/物理状态演化。
