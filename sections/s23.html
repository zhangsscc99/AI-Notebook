MemorySearchManager 源码结构

MemorySearchManager 是 OpenClaw memory 后端要实现的统一接口。上层工具不直接关心底层是 builtin SQLite 还是 QMD，它只调用 manager 的 search、readFile、sync、status 这类能力。

入口选择

getMemorySearchManager 根据配置选择后端。builtin 走 MemoryIndexManager，QMD 走 QmdMemoryManager。

builtin 主类

MemoryIndexManager 位于 manager.ts，负责 provider 初始化、search 入口、状态暴露、SQLite 连接和 builtin runtime 编排。

同步拆分

manager-sync-ops.ts 负责 watcher、interval sync、session sync、full reindex 判断、stale row 清理。

索引写入拆分

manager-embedding-ops.ts 负责 chunking、embedding batch、FTS 写入、vector 写入、embedding cache。

可以把源码分层理解成：

tools.ts
  -> getMemorySearchManager(...)
    -> MemoryIndexManager / QmdMemoryManager
      -> sync / search / readFile / status
        -> SQLite + FTS + sqlite-vec 或 QMD subprocess
