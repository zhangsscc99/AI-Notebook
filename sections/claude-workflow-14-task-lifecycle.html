C14

简述 Claude Code 完整的任务执行生命周期，按执行顺序拆解每一个环节。

完整生命周期分两层：外层 QueryEngine 接收任务并管理会话；内层 query.ts 反复跑模型-工具循环直到完成或中断。

接收输入：REPL / SDK / print / queued command 把 prompt 交给 submitMessage 或 ask。
处理输入：processUserInput() 解析 slash command、图片、paste、attachment、allowed tools、model override。
写入消息与 transcript：用户消息进入 mutableMessages，并尽早记录，保证可 resume。
准备系统环境：加载 system prompt、userContext、systemContext、tools、MCP、agents、skills、plugins、permission context。
进入 query：构造 QueryParams，调用 query({...})。
整理上下文：compact/snip/microcompact/collapse，拼接 system prompt。
调用模型：流式产出 assistant text/thinking/tool_use。
执行工具：权限检查、工具执行、生成 tool_result。
注入运行时上下文：queued command、task notification、memory、skill discovery、edited file attachment。
下一轮或收尾：有工具结果就继续；无工具就 stop hooks、budget/recovery 检查后完成。
输出结果：QueryEngine 把内部 Message 标准化成 SDKMessage / UI 消息 / result。
持久化清理：写 transcript、flush session storage、累计 usage/cost、更新 read file cache。
Prompt -> processUserInput -> mutableMessages/transcript -> system/tools/MCP/agents/skills -> query()
  -> context prepare -> call model -> tool_use -> run tools -> tool_result/attachments -> loop or terminal
  -> QueryEngine normalize -> SDK/UI result -> transcript/cache/usage 收尾
参考文件：src/QueryEngine.ts:209-1178、src/utils/processUserInput/processUserInput.ts、src/query.ts、src/utils/sessionStorage.ts。
