QueryEngine：会话生命周期的外壳

src/QueryEngine.ts 是 headless/SDK 路径的会话生命周期管理器。它持有 mutableMessages、permission denials、usage、read file cache、abort controller、已发现 skills、已加载 nested memory 等状态。每次用户提交消息都会进入 submitMessage()，但这些会话级状态会跨 turn 保留。

输入处理

调用 processUserInput() 解析用户 prompt、slash command、本地命令输出、attachments、memory 触发等，生成要追加到消息流里的 user/system 消息。

Transcript 持久化

用户消息在进入模型循环前就写 transcript，避免进程在 API 返回前被杀导致 --resume 找不到对话。

系统初始化

它会组装 tools、MCP clients、commands、agents、skills、plugins、permission mode、fast mode 等信息，并向 SDK 产出 system init message。

进入核心循环

真正的模型调用与工具循环交给 src/query.ts 的 query()；QueryEngine 负责接收其 yield 的消息、记录 transcript、计算 usage、输出 SDK result。
